Good to know

  • When a host cannot be reached, Cloudflare's Always Online serves a saved copy from Cloudflare's cache. If there is none, it takes static pages from the Internet Archive's Wayback Machine. developers.cloudflare.com
  • Always Online cannot serve dynamic content while the host is offline. Shopping carts and comment boxes show errors. developers.cloudflare.com
  • Always Online is on the Free, Pro, Business and Enterprise plans. Its archive crawl runs every 30 days on Free, every 15 days on Pro and every 5 days on Business and Enterprise. developers.cloudflare.com
  • Cloudflare Load Balancing runs health checks on each endpoint at set intervals. An endpoint fails if it does not answer, answers too slowly, or returns unexpected codes or content. developers.cloudflare.com
  • In Cloudflare Load Balancing, a pool that falls below its health threshold stops receiving traffic, and the traffic goes to the other pools. developers.cloudflare.com

What people ask

What do visitors see if my host is down?

With Cloudflare Always Online, they see a saved copy of the page. A banner says it is an archived version, with a Refresh button. If a page has no saved copy, they see the host's error page. developers.cloudflare.com

Does a saved copy work for a shop or a form?

Not with Always Online. Cloudflare says it cannot serve dynamic content while the host is offline, and visitors on shopping carts or comment boxes see errors. developers.cloudflare.com

How does a load balancer know a host is down?

Cloudflare's monitors send health check requests at set intervals. Each selected region runs checks from three data centers, and an endpoint is healthy if most regions are healthy. developers.cloudflare.com

What does storage for a backup copy cost?

Cloudflare R2 lists US$0.015 a GB a month, with the first 10 GB a month free. Sending data out of R2 through its APIs costs nothing. developers.cloudflare.com
