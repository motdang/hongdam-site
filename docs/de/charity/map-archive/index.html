Gut zu wissen

  • Eine Karte in Google My Maps beginnt mit einer Ebene und kann bis zu 10 haben. Ebenen gruppieren Elemente, zum Beispiel eine Ebene für Restaurants und eine für Cafés. support.google.com
  • Um eine Karte aus Google My Maps in eine Website einzubetten, muss sie öffentlich sein. Die Hilfeseite nennt zwei Freigabearten: Freigabe per Link, bei der man die URL bestimmten Personen gibt, und öffentlich, wobei jeder die Karte finden kann. support.google.com
  • uMap ist freie Open-Source-Software für Karten auf OpenStreetMap-Ebenen, und die Karten lassen sich auf die eigene Website setzen. Eine Gemeinschaft pflegt sie, und OpenStreetMap-Gruppen in Deutschland, der Schweiz und Frankreich betreiben Kopien. umap-project.org
  • Die Kachel-Richtlinie von OpenStreetMap erlaubt die Nutzung ihrer Kartenkacheln auf einer Website, wenn der OpenStreetMap-Hinweis deutlich auf der Karte steht. Sie begrenzt starke Nutzung, kann den Zugriff ohne Vorankündigung sperren und bietet nur bestmögliche Verfügbarkeit. operations.osmfoundation.org
  • Google schreibt, die Nutzung der Maps Embed API sei kostenlos. Sie braucht einen API-Schlüssel und hat keine Grenzen pro Sekunde oder pro Tag. developers.google.com

Was Leute fragen

Gibt es ein kostenloses Werkzeug für eine Karte von Orten?

uMap ist freie Open-Source-Software. Sie erstellt Karten auf OpenStreetMap-Ebenen und lässt sie sich auf die eigene Website setzen. umap-project.org

Kann eine Google-Karte kostenlos auf meine Website?

Google schreibt, die Nutzung der Maps Embed API sei kostenlos. Sie braucht einen API-Schlüssel und hat keine Grenzen pro Sekunde oder pro Tag. developers.google.com

Wie viele Ebenen kann eine Karte in Google My Maps haben?

Eine Karte entsteht mit einer Ebene und kann bis zu 10 haben. Die Hilfeseite von Google nennt als Beispiel eine Ebene für Restaurants und eine für Cafés. support.google.com

Lassen sich die Orte aus Google My Maps exportieren?

Ja. Die Hilfeseite sagt, eine Karte lasse sich als KML oder KMZ exportieren. Einzelne Ebenen gehen als CSV, ganze Karten nicht. support.google.com

Was kostet Felt, und gibt es einen Rabatt für Non-Profits?

Felts Gratis-Tarif erlaubt es, Karten zu erstellen und zu beschriften, sie öffentlich zu teilen und 10k Kartenaufrufe im Monat zu erhalten. Team kostet US$199 und Business US$599 im Monat, jährlich abgerechnet. US-Organisationen nach 501(c)(3) erhalten 30% Rabatt auf bezahlte Tarife. felt.com
