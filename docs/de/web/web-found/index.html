Gut zu wissen

  • Auf der Google-Seite zu KI-Funktionen steht, dass es keine zusätzlichen Anforderungen gibt, um in AI Overviews oder im AI Mode zu erscheinen. Eine Website muss keine neuen maschinenlesbaren Dateien, KI-Textdateien oder Auszeichnungen anlegen. Als unterstützender Link erscheint eine Seite nur, wenn sie indexiert ist (von Google gespeichert) und mit einem Snippet in der Suche angezeigt werden darf. developers.google.com
  • Auf der Google-Seite zu Titellinks steht, dass Google den Titel eines Suchergebnisses aus mehreren Quellen bildet. Dazu gehören das Title-Element der Seite, ihr sichtbarer Haupttitel, Überschriften wie h1 und og:title-Tags. Ein Titel soll aussagekräftig und knapp sein und sich von Seite zu Seite unterscheiden. Google kann einen neuen Titel bilden, wenn einer halb leer, veraltet, ungenau oder auf vielen Seiten wiederholt ist. developers.google.com
  • Google definiert eine Sitemap als Datei mit Angaben zu den Seiten, Videos und anderen Dateien einer Website. Eine Sitemap garantiert nicht, dass ihre Einträge gecrawlt, also vom Programm von Google besucht, und indexiert werden. Eine Website mit etwa 500 Seiten oder weniger, die intern gut verlinkt ist, gilt als klein, und Google sagt, eine solche Website braucht möglicherweise keine. developers.google.com
  • Eine robots.txt ist eine Textdatei, die Crawlern, den Programmen, die Seiten besuchen, mitteilt, auf welche URLs einer Website sie zugreifen dürfen. Laut Google dient sie hauptsächlich dazu, eine Website nicht mit Anfragen zu überlasten, und ist kein Mittel, eine Seite aus Google herauszuhalten. Eine in der robots.txt gesperrte Seite kann trotzdem indexiert werden, wenn andere Websites auf sie verlinken. developers.google.com
  • OpenAI nennt drei Crawler. OAI-SearchBot ist der Name, mit dem sich steuern lässt, wie eine Website in der ChatGPT-Suche erscheint. GPTBot sammelt Inhalte, die zum Training seiner Modelle dienen können. ChatGPT-User besucht eine Seite, wenn ein Nutzer darum bittet, und laut OpenAI gelten robots.txt-Regeln dafür möglicherweise nicht. Eine Änderung der robots.txt kann etwa 24 Stunden brauchen, bis sie die Suchsysteme von OpenAI erreicht. developers.openai.com
  • Anthropic nennt drei Bots. ClaudeBot sammelt Webinhalte, die zum Modelltraining beitragen können. Claude-User ruft Seiten ab, wenn ein Claude-Nutzer eine Frage stellt. Claude-SearchBot analysiert Inhalte, um Suchergebnisse zu verbessern. Laut Anthropic befolgen die Bots die robots.txt und unterstützen die nicht standardisierte Crawl-delay-Erweiterung. support.claude.com
  • Die llms.txt-Seite nennt dies einen Vorschlag, eine Datei namens llms.txt zu standardisieren, die KI-Agenten bei der Nutzung einer Website hilft. Die Datei ist in Markdown geschrieben, einem Klartextformat mit einfachen Zeichen, und liegt im Stammverzeichnis der Website oder unter einem Pfad darin. Nur die Überschrift erster Ebene mit dem Namen der Website ist Pflicht. Eine kurze Zusammenfassung und Linklisten sind optional. llmstxt.org

Was Leute fragen

Was kostet SEO in Thailand?

Die Agentur Relevant Audience in Bangkok sagt, SEO in Thailand koste im Allgemeinen etwa ฿20,000 bis ฿150,000 oder mehr im Monat. Für eine voll betreute Kampagne nennt sie ฿40,000 bis ฿60,000 im Monat als üblichen Einstieg. Auf ihrer Seite gehören technisches SEO, Inhalte, Linkaufbau, lokales SEO und Monatsberichte zum Angebot. relevantaudience.com

Was kostet SEO auf Fastwork?

Ein Verkäufer auf Fastwork bietet SEO- und KI-Ranking-Arbeit über Backlinks an, also Links von anderen Websites auf eine Website. Paket B kostet ฿3,000 für 500–700 Backlinks und einen Bericht über die gesetzten Links. Auf der Paketkarte stehen 7 Tage. Das Angebot zeigt 1.6K Verkäufe, eine Bewertung von 4.9 und eine Abschlussquote von 100%. Nur Paket B hat auf der Seite einen Preis. fastwork.co

Kostet es Geld, in den Google-Ergebnissen zu erscheinen?

Auf der Google-Seite zur Beauftragung eines SEO steht, dass das Erscheinen in den organischen Suchergebnissen von Google kostenlos ist. Dort steht auch, dass Google kein Geld nimmt, um Websites in diese Ergebnisse aufzunehmen oder zu ranken. developers.google.com

Kann jemand Platz eins bei Google garantieren?

Google erklärt, niemand könne Platz 1 bei Google garantieren. Ein SEO-Audit soll laut Google Schätzungen der Verbesserung liefern, die dem entsprechen, was machbar ist. developers.google.com

Wie viele Suchende klicken das erste Google-Ergebnis an?

In der Studie von Backlinko hat das erste Google-Ergebnis eine Klickrate von 27.6%. Die ersten drei Ergebnisse erhalten 54.4% aller Klicks. Nur 0.63% der Suchenden klicken auf der zweiten Seite etwas an. Die Seite von Backlinko wurde zuletzt am 16. April 2025 aktualisiert. backlinko.com

Braucht eine Website eine KI-Textdatei, um in den KI-Antworten von Google zu erscheinen?

Auf der Google-Seite zu KI-Funktionen steht, dass eine Website keine neuen maschinenlesbaren Dateien, KI-Textdateien oder Auszeichnungen anlegen muss, um in AI Overviews oder im AI Mode zu erscheinen. Eine Seite muss indexiert sein und mit einem Snippet in der Suche angezeigt werden dürfen. Dieselbe Seite nennt robots.txt-Regeln für Googlebot als Weg, wie Website-Betreiber den Zugriff steuern. developers.google.com

Braucht eine kleine Website eine Sitemap?

Google sagt, eine Website mit etwa 500 Seiten oder weniger, die intern gut verlinkt ist, braucht möglicherweise keine Sitemap. Eine neue Website mit wenigen Links von anderen Websites kann eine brauchen, weil Googlebot Seiten, auf die keine andere Website verlinkt, vielleicht nicht findet. Google sagt auch, eine Sitemap garantiere nicht, dass ihre Einträge gecrawlt und indexiert werden. developers.google.com

Liest Google die Handy- oder die Desktop-Version einer Seite?

Google sagt, es nutzt für Indexierung und Ranking die mobile Version der Inhalte einer Website, mit dem Smartphone-Agenten gecrawlt. Für die Indexierung zählen nur Inhalte, die auf der mobilen Website gezeigt werden. Google empfiehlt responsives Webdesign, bei dem Inhalt und Metadaten auf Handy und Desktop gleich sind. developers.google.com
