Gut zu wissen

  • WordPress hat eine REST-API mit Endpunkten für Beiträge, Seiten, Taxonomien und andere eingebaute Datentypen. Anwendungen senden und empfangen dort JSON, um Inhalte abzufragen, zu ändern und zu erstellen. developer.wordpress.org
  • Eine Anfrage an /wp-json/wp/v2/posts liefert eine Sammlung von Beiträgen; die Standardwerte sind 10 pro Seite, Status publish und Kontext view. developer.wordpress.org
  • WordPress 6.9 brachte die Abilities API, ein Register, in dem Plugins, Themes und der Kern in maschinenlesbarer Form beschreiben, was sie können. Der Beitrag vom 10. November 2025 nennt sie die Grundlage für KI-Agenten und Automatisierungswerkzeuge. make.wordpress.org
  • Die REST-Endpunkte der Abilities API liegen unter wp-abilities/v1 und gibt es nur für Abilities, die mit show_in_rest = true registriert sind. Laut dem Beitrag braucht es einen authentifizierten Benutzer. make.wordpress.org

Was Leute fragen

Hat WordPress schon eine API?

Ja, eine REST-API gehört zu WordPress. Sie bietet Endpunkte für Beiträge, Seiten, Taxonomien und andere eingebaute Datentypen und liefert JSON. developer.wordpress.org

Was ist die WordPress Abilities API?

Es ist ein System in WordPress 6.9, in dem Plugins, Themes und der Kern ihre Funktionen in einer standardisierten, maschinenlesbaren Form registrieren. Eine Ability braucht ein Label, eine Beschreibung, eine Kategorie, Ein- und Ausgabeschemata, einen Execute-Callback und einen Permission-Callback. make.wordpress.org

Wie meldet sich eine andere App an der WordPress-REST-API an?

Die Cookie-Authentifizierung ist die Standardmethode von WordPress, für angemeldete Benutzer innerhalb von WordPress. Andere Apps übergeben mit Anwendungspasswörtern ihre Zugangsdaten über HTTPS per Basic Auth. developer.wordpress.org
