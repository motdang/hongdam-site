Was Leute fragen

Gibt es ein kostenloses Wetter-Widget für eine Website?

Die Wetter-API von Open-Meteo ist für nichtkommerzielle Nutzung kostenlos, bis 10,000 Abrufe pro Tag. Die kostenpflichtigen Pläne decken kommerzielle Nutzung ab, ab 1 Million Abrufen im Monat. open-meteo.com

Kann eine Box den PM2,5-Wert meiner Stadt zeigen?

Open-Meteo führt PM2,5 unter den stündlichen Luftqualitätsvariablen auf, dazu einen US-AQI und einen europäischen AQI. Die globale Prognose liegt auf einem Raster von 0,4°, etwa 45 km. open-meteo.com

Kann die Box den Standort des Besuchers selbst ermitteln?

Eine Seite kann den Standort eines Besuchers nur in einem sicheren Kontext lesen, also über HTTPS. Der Browser fragt den Besucher vorher um Erlaubnis. developer.mozilla.org

Was bedeutet PM2,5?

PM2,5 sind feine Partikel in der Luft mit einem Durchmesser von höchstens 2,5 Mikrometern. Die WHO schreibt, dass sie in die Lunge eindringen und ins Blut gelangen können. who.int
