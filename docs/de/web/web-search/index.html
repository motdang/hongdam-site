Was Leute fragen

Wie füge ich meiner Website ein Suchfeld hinzu?

Eine Bibliothek für statische Seiten wie Pagefind legt ein Suchpaket in die erzeugten Dateien, und die Suche läuft im Browser des Besuchers. Ein gehosteter Suchdienst ist dafür nicht nötig. pagefind.app

Kann ich Google verwenden, um meine eigene Website zu durchsuchen?

Die Custom Search JSON API von Google steht Neukunden nicht mehr offen. Bestehende Kunden haben bis zum 1. Januar 2027 Zeit zum Wechsel, und Google nennt Vertex AI Search für die Suche in bis zu 50 Domains. developers.google.com

Funktioniert die Suche auf der Website auf Thai?

Thai setzt keine Leerzeichen zwischen die Wörter, wer an Leerzeichen trennt, erhält deshalb falsche Wörter. Browser bieten Intl.Segmenter, um Thai und ähnliche Sprachen in Wörter zu teilen; es ist seit April 2024 browserübergreifend verfügbar. developer.mozilla.org

Was kostet eine gehostete Website-Suche?

Der Gratisplan von Algolia enthält 10,000 Suchanfragen im Monat und 50,000 Datensätze. Im Plan Grow kosten zusätzliche Anfragen US$0.50 pro 1,000 und zusätzliche Datensätze US$0.40 pro 1,000. algolia.com
