Gut zu wissen

  • Die Mail-Einträge von Google Workspace nutzen den MX-Wert smtp.google.com mit Priorität 1 (ein MX-Eintrag ist die Zeile in den Einstellungen einer Domain, die sagt, wohin ihre Mail geht). Laut Googles Seite kann es bis zu 72 Stunden dauern, bis neue MX-Einträge erkannt werden; das Entfernen anderer MX-Einträge steht dort als Schritt. knowledge.workspace.google.com
  • Microsoft 365 braucht für die Mail einer eigenen Domain einen MX-Eintrag. Ein Autodiscover-CNAME-Eintrag und ein SPF-TXT-Eintrag sind optional; Microsofts Seite nennt sie dringend empfohlen. Sobald sich der MX-Eintrag ändert, geht alle neue Mail der Domain an Microsoft 365. Bestehende Mail bleibt beim bisherigen Anbieter, solange sie nicht übertragen wird. learn.microsoft.com
  • Gmail verlangt von allen Absendern SPF oder DKIM. Wer mehr als 5,000 Nachrichten pro Tag an Gmail-Konten sendet, braucht SPF, DKIM und DMARC (drei Einträge, die zeigen, dass eine Nachricht von der genannten Domain stammt). Die DMARC-Richtlinie darf auf none stehen. support.google.com
  • Cloudflare Email Routing nimmt Mail an eine Adresse der Domain entgegen und leitet sie an ein anderes Ziel weiter. Es versendet keine Mail; das Versenden ist ein eigenes Cloudflare-Produkt. developers.cloudflare.com

Was Leute fragen

Was kostet Google Workspace in Thailand?

Auf Googles thailändischer Preisseite stehen Starter mit ฿275, Standard mit ฿550 und Plus mit ฿850 pro Nutzer und Monat, ohne Steuer. Für Neukunden zeigt die Seite ฿137.50 für Starter und ฿330 für Standard, für die ersten 20 Nutzer und die ersten 12 Monate. workspace.google.com

Gibt es einen kostenlosen Weg zu E-Mail unter der eigenen Domain?

Cloudflare Email Routing gibt es im kostenlosen Tarif von Cloudflare. Es leitet Mail, die an eine Adresse der Domain geht, an ein anderes Ziel weiter und versendet keine Mail. Das Versenden ist ein eigenes Produkt und läuft im Beta-Stadium im bezahlten Workers-Tarif. developers.cloudflare.com

Wie lange dauert es, bis Mail nach dem Ändern der MX-Einträge ankommt?

Laut Googles Seite kann es bis zu 72 Stunden dauern, bis neue MX-Einträge erkannt werden. Die Seite fügt an, dass Mail erst fliessen kann, wenn auch der Gmail-Aktivierungsschritt in der Admin-Konsole erledigt ist. knowledge.workspace.google.com

Welche Einträge verlangt Gmail von einer Absender-Domain?

Gmail verlangt von allen Absendern SPF oder DKIM. Wer mehr als 5,000 Nachrichten pro Tag an Gmail-Konten sendet, braucht SPF, DKIM und DMARC. Dieselbe Seite nennt eine Spam-Rate unter 0.3% in den Postmaster Tools. support.google.com

Lassen sich Outlook und Microsoft 365 für Mail unter der eigenen Domain nutzen?

Ja. Auf Microsofts Seite steht, wie sich eine anderswo gekaufte Domain verbinden lässt, indem man beim Registrar DNS-Einträge hinzufügt; die Domain bleibt dort registriert. Ohne eigene Domain wird eine onmicrosoft.com-Adresse verwendet. learn.microsoft.com
