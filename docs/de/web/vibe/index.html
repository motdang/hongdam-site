Was Leute fragen

Kann jemand anderes eine mit Lovable gebaute App reparieren?

Auf Lovables GitHub-Seite steht, dass sich jedes Projekt mit einem GitHub-Repository synchronisieren lässt. Das Repository lässt sich klonen und im gewohnten Editor weiterbearbeiten; Änderungen im aktiven Branch werden zurück nach Lovable synchronisiert. docs.lovable.dev

Kann jeder eine Tabelle lesen, wenn Row Level Security aus ist?

Laut Supabase ist eine Tabelle in einem freigegebenen Schema ohne RLS für jede Rolle mit einer Berechtigung les- und schreibbar. Ist RLS aktiv, liefert die API einem publishable key keine Daten, bis Richtlinien angelegt sind. supabase.com

Wohin gehört ein Zahlungsschlüssel in einer App?

Auf Stripes Seite steht, geheime API-Schlüssel gehörten in die Serverumgebung, nie in den Quellcode und nie eingebettet in Apps. Publishable keys dürfen in Webseiten und Apps stehen. docs.stripe.com

Was kostet es, eine mit KI gebaute App reparieren zu lassen?

Auf Aibrifys Seite steht eine Diagnose für US$100, geliefert innerhalb von 24 Stunden und auf die Reparatur angerechnet. Eine Reparatur kostet meist US$100 oder US$300, eine Sicherheitsprüfung der ganzen App US$300 und das Stabilisieren einer wackligen App US$1,000. aibrify.com
