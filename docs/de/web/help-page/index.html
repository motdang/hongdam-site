Gut zu wissen

  • Eine Seite kann den Standort eines Besuchers nur in einem sicheren Kontext (HTTPS) lesen, und der Browser holt vorher ausdrücklich die Erlaubnis des Besuchers ein. developer.mozilla.org
  • Das tel-URI-Schema (RFC 3966, Dezember 2004) beschreibt Ressourcen, die durch Telefonnummern bezeichnet werden. rfc-editor.org
  • LINE zählt Broadcast-Nachrichten einmal pro erreichter Person; Antworten zählen nicht zum Monatskontingent. developers.line.biz
  • Maps URLs erzeugen einen plattformübergreifenden Link, der Google Maps für eine Suche, eine Route, eine Karte oder Street View öffnet. Die Seite hält fest, dass kein Google-API-Schlüssel nötig ist. developers.google.com

Was Leute fragen

Woher weiss eine Seite, wo der Kunde ist?

Der Browser kann der Seite den Standort des Besuchers geben, aber nur auf HTTPS-Seiten und erst, wenn der Besucher in einer Abfrage zustimmt. developer.mozilla.org

Was kostet eine Live-Karte auf der Website eines Pannendienstes?

Google Maps Platform gibt im Monat 10,000 kostenlose Kartenladungen und 10,000 kostenlose Routenanfragen. Danach kostet eine Kartenladung US$7 pro 1,000 und eine Routenanfrage US$5 pro 1,000. Die Seite wurde zuletzt am 2026-10-21 aktualisiert. developers.google.com

Gibt es Software für Abschleppunternehmen?

Towbook verkauft Dispositionssoftware für Abschleppdienste zu US$109 bis US$429 im Monat für 250 bis 1,500 Einsätze. Zusätzliche Einsätze kosten US$149 pro 1,000. towbook.com
