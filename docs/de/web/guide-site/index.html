Was Leute fragen

Kann ich OpenStreetMap für eine Karte für Besucher auf meiner Website nutzen?

Die Kachelserver von OpenStreetMap bedienen Apps und Websites unter Bedingungen: Namensnennung auf der Karte, ein korrekter Referer-Header und kein Massen-Download. Die Richtlinie hält zudem fest, dass die Server über Spenden und Sponsoring finanziert werden und ihre Kapazität begrenzt ist. operations.osmfoundation.org

Was kostet eine Google-Karte auf meiner Website?

Google Maps Platform gibt für die Maps JavaScript API 10,000 kostenlose Kartenladungen im Monat, danach US$7 pro 1,000. Static Maps ist für die ersten 10,000 kostenlos, danach US$2 pro 1,000. Die Seite wurde zuletzt am 2026-10-21 aktualisiert. developers.google.com

Darf ein Ausländer in Thailand als Reiseleiter arbeiten?

Das thailändische Recht verbietet Ausländern die Arbeit als Reiseleiter, wie Khaosod English im März 2023 berichtete. khaosodenglish.com

Kann ein Link im Reiseführer die Route in Google Maps öffnen?

Maps URLs erzeugen einen plattformübergreifenden Link, der Google Maps für eine Suche, eine Route, eine Karte oder Street View öffnet. Die Seite hält fest, dass kein Google-API-Schlüssel nötig ist. developers.google.com
