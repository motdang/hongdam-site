Gut zu wissen

  • Ende 2025 hatte LINE in Thailand 56 Millionen monatlich aktive Nutzende, das sind 78.2% der Bevölkerung. Im Oktober 2025 nutzten 82.6% der Internetnutzenden in Thailand LINE aktiv. datareportal.com
  • Ein LINE Official Account in Thailand hat drei Tarife: Free mit 300 Nachrichten im Monat, Basic für ฿1,280 mit 15,000 Nachrichten und Pro für ฿1,780 mit 35,000. Die Preise verstehen sich ohne 7% MwSt. Zusätzliche Nachrichten kosten bei Basic ฿0.10 pro Stück und bei Pro ฿0.06. lineforbusiness.com
  • LINE zählt Nachrichten nach der Zahl der Personen, die sie erhalten. Eine Nachricht an fünf Personen zählt als fünf. Antwortnachrichten (Reply) zählen nicht. Push-, Multicast-, Broadcast- und Narrowcast-Nachrichten zählen. developers.line.biz
  • Wenn jemand das Konto hinzufügt oder ihm schreibt, schickt LINE ein Webhook-Ereignis an die Adresse des Bot-Servers. Das Ereignis nennt die Nutzer-ID der Absenderin oder des Absenders, und das Feld destination nennt die ID des Bots, der es erhalten hat. developers.line.biz
  • Ein Rich Menu ist ein Menü im LINE-Chat. Die Messaging API kann ein Rich Menu für eine einzelne Person festlegen. Diese Person sieht es anstelle des Standard-Rich-Menus des Kontos. developers.line.biz
  • Ein Link der Form line.me/R/oaMessage/ gefolgt von der ID des Kontos öffnet einen Chat mit diesem Konto, mit bereits eingetipptem Text. Er funktioniert in LINE für iOS und Android, nicht in LINE für PC. developers.line.biz

Was Leute fragen

Ist ein LINE-Chatbot gratis?

Antwortnachrichten (Reply) eines Chatbots zählen nicht zur Nachrichtenmenge eines Tarifs. Push-, Multicast-, Broadcast- und Narrowcast-Nachrichten zählen, eine pro Person, die sie erhält. Bei einem Tarif ohne Zusatznachrichten kann ein Konto nach Überschreiten seiner Menge nicht mehr senden, und LINE gibt einen Fehler zurück. Tarife mit Zusatznachrichten rechnen diese pro Nachricht ab. developers.line.biz

Was kostet ein LINE Official Account im Monat?

Der Tarif Free kostet nichts und hat 300 Nachrichten im Monat. Basic kostet ฿1,280 im Monat für 15,000 Nachrichten. Pro kostet ฿1,780 im Monat für 35,000. Die Preise verstehen sich ohne 7% MwSt. Zusätzliche Nachrichten kosten bei Basic ฿0.10 und bei Pro ฿0.06 pro Stück. lineforbusiness.com

Was ist die LINE Messaging API?

Sie lässt einen Bot-Server mit einem LINE Official Account zusammenarbeiten. Ein Bot kann Antwortnachrichten an Personen senden, die das Konto hinzugefügt haben, jederzeit Nachrichten senden, Ereignisse über einen Webhook empfangen und Rich Menus festlegen. LINE sagt, der Start sei gratis. developers.line.biz

Was ist der Webhook eines LINE-Chatbots?

Ein Webhook ist eine Adresse auf dem Server des Bots. LINE schickt das Ereignis per HTTP POST dorthin. Der Server gibt einen 2xx-Code zurück. Tut er das nicht und ist die Wiederzustellung eingeschaltet, sendet LINE das Ereignis erneut. LINE kann das Senden einstellen, wenn der Server lange nichts empfängt. developers.line.biz

Kann ein LINE-Konto verschiedenen Kundinnen und Kunden verschiedene Menüs zeigen?

Ja, mit Rich Menus. Die Messaging API kann ein Rich Menu für eine einzelne Person festlegen. Freundinnen und Freunde sehen das Standard-Rich-Menu, ausser sie sind mit einem eigenen Rich Menu verknüpft. developers.line.biz

Kann ein Link einen LINE-Chat mit vorgetipptem Text öffnen?

Ja. Die Adresse lautet line.me/R/oaMessage/ gefolgt von der ID des Kontos, dann ein ? und der Text. ID und Text sind prozentkodiert. Der Link funktioniert in LINE für iOS und Android, nicht in LINE für PC. developers.line.biz
