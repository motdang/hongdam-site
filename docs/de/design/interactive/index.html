Was sagen die WCAG zu bewegten Inhalten auf einer Seite?

Das Erfolgskriterium 2.2.2 der Stufe A betrifft bewegte, blinkende oder scrollende Informationen, die automatisch beginnen, länger als fünf Sekunden dauern und neben anderen Inhalten stehen. Es verlangt, dass Nutzende sie anhalten, stoppen oder ausblenden können. Bewegung, die für die Aktivität wesentlich ist, nimmt es aus. w3.org
