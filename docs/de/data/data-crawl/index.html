Gut zu wissen

  • Eine robots.txt-Datei sagt Crawlern von Suchmaschinen, welche URLs sie auf einer Website aufrufen dürfen. Laut Google hält sie eine Seite nicht aus Google heraus, und ob ein Crawler sie befolgt, liegt bei ihm. developers.google.com
  • RFC 9309, der Standard für robots.txt, hält fest, dass seine Regeln keine Zugriffsberechtigung sind. Crawler werden nur gebeten, sie zu befolgen. rfc-editor.org
  • Das thailändische Datenschutzgesetz (PDPA) gilt für Angaben, die eine natürliche Person erkennbar machen (Section 6). Holt ein Unternehmen solche Angaben aus einer anderen Quelle als von der Person selbst, verlangt Section 25 die Information binnen 30 Tagen und die Zustimmung, ausser es gilt eine Ausnahme. cc.kmutt.ac.th
  • Die Bedingungen von Google Maps Platform (Ziffer 3.2.3) verbieten es Kunden, Inhalte von Google Maps zur Nutzung ausserhalb der Dienste auszulesen, darunter das Kopieren und Speichern von Firmennamen, Adressen oder Nutzerbewertungen. cloud.google.com

Was Leute fragen

Kann eine Website Crawler fernhalten?

Ja. Eine Website veröffentlicht eine robots.txt-Datei mit den URLs, die ein Crawler öffnen darf. Laut Google liegt es beim Crawler, die Datei zu befolgen. Google sagt auch, dass die Datei eine Seite nicht aus Google heraushält. developers.google.com

Wie hoch ist das Bussgeld nach dem thailändischen Datenschutzgesetz?

Section 83 setzt für Verstösse gegen Section 25 Absatz 1, also das Erheben personenbezogener Daten aus einer anderen Quelle als von der Person selbst, ein Verwaltungsbussgeld bis ฿3 Millionen fest. Section 84 setzt bis ฿5 Millionen fest für das Erheben von Daten wie Gesundheit, Religion oder biometrischen Daten ohne ausdrückliche Zustimmung (Section 26). cc.kmutt.ac.th

Darf ein Crawler Firmennamen aus Google Maps kopieren?

Nach den Bedingungen von Google Maps Platform nicht. Ziffer 3.2.3 nennt das Kopieren und Speichern von Firmennamen, Adressen oder Nutzerbewertungen unter dem, was Kunden mit Inhalten von Google Maps nicht tun. cloud.google.com
