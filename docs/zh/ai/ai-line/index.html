  • 泰国的 LINE 官方账号有三个套餐：Free 每月 300 条消息；Basic ฿1,280，含 15,000 条；Pro ฿1,780，含 35,000 条。价格不含 7% 增值税。超出的消息，Basic 每条 ฿0.10，Pro 每条 ฿0.06。 lineforbusiness.com
  • LINE 按收到消息的人数计数。一条消息发给五个人，算五条。回复消息（reply）不计数。推送（push）、多播（multicast）、广播（broadcast）和窄播（narrowcast）消息都计数。 developers.line.biz
  • 有人添加账号为好友或给账号发消息时，LINE 会向机器人服务器的地址发送一个 webhook 事件。事件里有发送者的用户 ID，destination 字段则是接收消息的机器人的 ID。 developers.line.biz
  • Rich menu 是 LINE 聊天里的菜单。Messaging API 可以为单个用户设置 rich menu，该用户看到的是它，而不是账号的默认 rich menu。 developers.line.biz
  • 形如 line.me/R/oaMessage/ 加账号 ID 的链接，会打开与该账号的聊天，并预先填好文字。它适用于 iOS 和 Android 版 LINE，不适用于电脑版 LINE。 developers.line.biz

大家常问

LINE 聊天机器人免费吗

聊天机器人的回复消息（reply）不计入套餐的消息额度。推送（push）、多播、广播和窄播消息会计数，每个收到的人算一条。在没有额外消息的套餐上，账号超出额度就发不出去，LINE 返回错误。出售额外消息的套餐按条收费。 developers.line.biz

LINE 官方账号一个月多少钱

Free 套餐免费，每月 300 条消息。Basic 每月 ฿1,280，含 15,000 条。Pro 每月 ฿1,780，含 35,000 条。价格不含 7% 增值税。额外的消息，Basic 每条 ฿0.10，Pro 每条 ฿0.06。 lineforbusiness.com

LINE Messaging API 是什么

它让机器人服务器与 LINE 官方账号对接。机器人可以向添加了账号的人发送回复消息，随时发送消息，通过 webhook 接收事件，并设置 rich menu。LINE 说明可以免费开始使用。 developers.line.biz

LINE 聊天机器人的 webhook 是什么

Webhook 是机器人服务器上的一个地址。LINE 把事件用 HTTP POST 发到这个地址。服务器返回 2xx 状态码。如果没有返回，且开启了重发，LINE 会再发一次该事件。服务器长时间收不到时，LINE 可能停止发送。 developers.line.biz

一个 LINE 账号能给不同顾客显示不同的菜单吗

可以，用 rich menu。Messaging API 可以为单个用户设置 rich menu。除非用户被关联了自己的 rich menu，否则好友看到的是默认的 rich menu。 developers.line.biz

一个链接能打开 LINE 聊天并预先填好文字吗

可以。地址是 line.me/R/oaMessage/ 加账号 ID，再加 ? 和文字。ID 和文字要做百分号编码。它适用于 iOS 和 Android 版 LINE，不适用于电脑版 LINE。 developers.line.biz
