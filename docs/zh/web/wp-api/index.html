须知

  • WordPress 有一套 REST API，为文章、页面、分类法和其他内置数据类型提供端点。应用在这些端点收发 JSON，用来查询、修改和创建内容。 developer.wordpress.org
  • 向 /wp-json/wp/v2/posts 发出请求会返回文章集合；默认每页 10 篇，状态为 publish，上下文为 view。 developer.wordpress.org
  • WordPress 6.9 新增 Abilities API，这是一个注册表，插件、主题和核心用机器可读的形式在其中描述自己能做什么。2025 年 11 月 10 日的文章称它是 AI 代理和自动化工具的基础。 make.wordpress.org

大家常问

WordPress 本身有 API 吗？

有。WordPress 自带 REST API，为文章、页面、分类法和其他内置数据类型提供端点，并返回 JSON。 developer.wordpress.org

WordPress Abilities API 是什么？

这是 WordPress 6.9 中的一个系统，插件、主题和核心用标准的机器可读形式注册自己的功能。一个 ability 需要标签、描述、分类、输入和输出模式、执行回调和权限回调。 make.wordpress.org

其他应用怎样登录 WordPress REST API？

Cookie 认证是 WordPress 的标准方式，适用于在 WordPress 内已登录的用户。其他应用可用应用密码，通过 HTTPS 以 Basic Auth 传送凭据。 developer.wordpress.org

定制一个 WordPress 插件要多少钱？
