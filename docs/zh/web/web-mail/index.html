须知

  • Google Workspace 的邮件记录使用 MX 值 smtp.google.com，优先级为 1（MX 记录是域名设置里指明邮件送往何处的一行）。Google 页面写明，新的 MX 记录最长可能要 72 小时才被识别，并把删除其他 MX 记录列为一个步骤。 knowledge.workspace.google.com
  • Microsoft 365 为自有域名的邮件需要一条 MX 记录。Autodiscover CNAME 记录和 SPF TXT 记录是可选的，微软页面称强烈建议添加。MX 记录一改，该域名之后的新邮件全部送到 Microsoft 365，已有邮件仍留在原来的邮件服务商那里，除非迁移。 learn.microsoft.com
  • Gmail 要求所有发件人至少有 SPF 或 DKIM。每天向 Gmail 账户发送超过 5,000 封的发件人，需要 SPF、DKIM 和 DMARC（三者都是证明邮件来自其所称域名的记录）。DMARC 的策略可以设为 none。 support.google.com
  • Cloudflare Email Routing 把发到域名下某个地址的来信转交给别的目的地。它不负责发信，发信是 Cloudflare 的另一项产品。 developers.cloudflare.com

大家常问

Google Workspace 在泰国多少钱？

Google 泰语价格页列出：Starter 每用户每月 ฿275，Standard ฿550，Plus ฿850，不含税。新客户的前 20 位用户、前 12 个月，页面显示 Starter 为 ฿137.50，Standard 为 ฿330。 workspace.google.com

有没有免费的自有域名邮箱办法？

Cloudflare Email Routing 在 Cloudflare 的免费套餐中提供。它把发到域名地址的邮件转交给别处，不负责发信。发信是另一项产品，在 Workers 付费套餐中处于测试阶段。 developers.cloudflare.com

改了 MX 记录后，邮件多久开始到？

Google 页面写明，新的 MX 记录最长可能需要 72 小时才被识别。页面还说，管理控制台里的 Gmail 启用步骤也要完成，邮件才可能开始流入。 knowledge.workspace.google.com

Gmail 要求发信域名有哪些记录？

Gmail 要求所有发件人有 SPF 或 DKIM。每天向 Gmail 账户发送超过 5,000 封的发件人，需要 SPF、DKIM 和 DMARC。同一页面还写明 Postmaster Tools 中的垃圾邮件率低于 0.3%。 support.google.com

Outlook 和 Microsoft 365 能用在自己的域名邮箱上吗？

可以。微软页面说明，在别处买的域名可在注册商处添加 DNS 记录来连接，域名仍登记在原注册商。不添加自有域名时，使用 onmicrosoft.com 地址。 learn.microsoft.com
