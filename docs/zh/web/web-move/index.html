须知

  • 对于不改 URL 的主机迁移，Google 页面列出这些步骤：在临时主机名上复制并测试网站，至少提前一周把 DNS TTL（其他计算机保留旧 DNS 答复的时长）降到几个小时，然后更新 DNS 记录。流量从旧服务器转到新服务器，旧主机的流量降到零后即可关闭。 developers.google.com
  • WordPress 文档写明，迁移从备份文件和数据库开始。数据库和 URL 不变时，复制文件和数据库即可迁移网站；地址变了，页面按顺序列出九个步骤。 developer.wordpress.org

  • Wix 表示，域名在注册后、注册人联系信息变更后或上次转移后的 60 天内不能转移。这一限制同样适用于从 Wix 转出。 support.wix.com
  • 微软页面写明，域名的 MX 记录改到 Microsoft 365 后，该域名之后的新邮件全部送到那里，已有邮件仍留在原来的邮件服务商那里，除非迁移。 learn.microsoft.com

大家常问

Wix 网站能迁到别的主机吗？

Wix 表示，Wix 网站不能导出或托管到别处，因为它必须在 Wix 的服务器上运行。该页面说，您做出来的内容归您所有，域名可以连接到 Wix 网站，也可以交给别的服务商管理。 support.wix.com

域名转移前要等一段时间吗？

Wix 表示，域名在注册后、注册人联系信息变更后或上次转移后的 60 天内不能转移。这一限制同样适用于从 Wix 转出，Wix 无法更改。在此期间，域名可留在 Wix 账户里，指向外部网站。 support.wix.com

WordPress 网站怎样迁到新服务器？

WordPress 文档先从备份文件和数据库讲起。数据库和 URL 不变时，把文件和数据库复制过去。地址变了，页面按顺序列出九个步骤，包括修改 URL 和 wp-config.php 里的设置。 developer.wordpress.org

切换到新主机是怎么发生的？

按 Google 的步骤，测试完副本后，把 DNS 记录改为指向新主机。TTL 至少提前一周降到几个小时，公共 DNS 检测工具可以显示全球的网络服务商是否已采用新设置。流量从旧服务器转到新服务器。 developers.google.com
