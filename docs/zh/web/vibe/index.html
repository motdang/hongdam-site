须知

  • Lovable 把每个项目连到它创建的 GitHub 仓库。在 Lovable 里的改动同步到 GitHub，推送到当前分支的改动也同步回来。仓库可以克隆到本地，用自己习惯的编辑器继续做；付费套餐还能下载整个代码库。 docs.lovable.dev
  • Supabase 页面写明，暴露的 schema 里没有开启行级安全（RLS，规定谁能读或改表中每一行的规则）的表，任何拥有授权的角色都可读可写。开启 RLS 后，在创建策略之前，API 不会向 publishable key 返回数据。 supabase.com
  • Stripe 页面写明，密钥（secret API key，即让软件能在 Stripe 账户上操作的代码）属于服务器环境，不写进源代码，也不嵌入应用。publishable key 可以放在网页和应用中。 docs.stripe.com
  • Aibrify 针对 Lovable 应用的页面列出这些问题：白屏、登录失败、用户看到或改动他人的数据、发布失败、线上应用与预览不一致、数据保存不了、没有行级安全的表，以及只应在服务器端使用的密钥暴露在浏览器里。 aibrify.com

大家常问

别人能修用 Lovable 做的应用吗？

Lovable 的 GitHub 页面写明，每个项目都可以与一个 GitHub 仓库同步。仓库可以克隆下来，用习惯的编辑器继续做，推送到当前分支的改动会同步回 Lovable。 docs.lovable.dev

没开行级安全时，任何人都能读表吗？

Supabase 页面写明，暴露的 schema 里没有开启 RLS 的表，任何拥有授权的角色都可读可写。开启 RLS 后，在创建策略之前，API 不会向 publishable key 返回数据。 supabase.com

收款用的密钥应该放在应用的哪里？

Stripe 页面写明，密钥（secret API key）属于服务器环境，不写进源代码，也不嵌入应用。publishable key 可以放在网页和应用中。 docs.stripe.com

请人修 AI 做的应用要多少钱？

Aibrify 页面列出：诊断 US$100，24 小时内交付，费用计入修复。一项修复通常 US$100 或 US$300，整个应用的安全检查 US$300，让不稳定的应用稳定下来 US$1,000。 aibrify.com
