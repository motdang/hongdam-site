须知

  • LY Corporation（LINE 背后的公司）统计，截至 2026 年 3 月 31 日，泰国 LINE 月活跃用户为 5,400 万，占人口的 81.8%，所依据的是内政部公布的 2024 年人口约 6,595 万。 lycorp.co.jp
  • LINE MINI App 是运行在 LINE 上的网页应用。用户可以从 LINE 内部、固定链接、LINE 官方账号、首页标签、搜索或别人分享的消息中打开它。 developers.line.biz
  • 新建的 LINE MINI App 频道起初是未认证的 MINI App，部分功能受限。面向泰国的服务，只有认证服务商（certified provider）名下的频道才能申请认证审核。 developers.line.biz
  • LINE 按请求数乘以接收人数来计算消息。回复消息不计入套餐的消息数，发给已屏蔽该账号的用户的消息也不计入。 developers.line.biz
  • Messaging API 文档说明，超过每月消息上限后，会返回错误响应，消息不会发出。 developers.line.biz
  • LINE 官方账号通过 LINE 审核后，会获得认证标识（Verified account badge）。LINE 目前只在日本、台湾和泰国受理申请，其他国家或地区暂不发放认证账号。 help.line.me

大家常问

什么是 LINE 官方账号

LINE 泰国把它描述为企业在 LINE 上的官方账号。商店用它积累关注者，并向顾客发送促销和优惠信息。功能包括欢迎消息、自动回复、优惠券和积分卡、一对一聊天以及群发消息。 lineforbusiness.com

开通 LINE OA 要花钱吗

开通官方账号后，每月有 300 条免费消息。LINE 泰国另外出售两个月度套餐：Basic ฿1,280，含 15,000 条消息；Pro ฿1,780，含 35,000 条。两个价格都不含 7% 增值税。 lineforbusiness.com

怎样登录 LINE OA

在电脑上，LINE Official Account Manager 的地址是 manager.line.biz；在手机上用 Official Account 应用。两种方式都用 LINE 账号或商务账号登录。 lineforbusiness.com

LINE MINI App 和 LIFF 有什么区别

LY Corporation 表示，LIFF 最终会并入 LINE MINI App 品牌，并推荐把新的 LIFF 应用做成 LINE MINI App。MINI App 少了几项 LIFF 功能：操作按钮不能隐藏，不能设置 Module Mode，一个频道只能放一个网页应用，屏幕尺寸固定为 Full。 developers.line.biz

LINE MINI App 由谁来做

由开发者来做。LINE Developers 说明，创建 LINE MINI App 频道需要 LINE Developers Console 账号。这个应用是运行在 LINE 上的网页应用。 developers.line.biz

LINE OA 能开店吗

LINE 泰国在套餐旁列出 MyShop，这是为 LINE OA 搭建店面、帮助成交的工具。通过 MyShop 完成的订单，按 LINE 设定的条件收取费用。 lineforbusiness.com

顾客能在 LINE 里预订并付订金吗

Fastwork 上的卖家出售通过 LINE OA 预订的系统。在其中一个商品页里，入门套餐接受预订，并把预订通知发到 LINE OA；下一档加上附转账凭证的订金支付和假凭证检查；最高档再加上预约前的提醒、改期和取消。 fastwork.co
