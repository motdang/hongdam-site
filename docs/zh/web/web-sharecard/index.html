须知

  • Open Graph 协议为页面列出四个必填属性：og:title、og:type、og:image 和 og:url。og:image 是代表该页面的图片的 URL；og:image:alt 是配套属性，用来描述这张图片。 ogp.me
  • Meta 的分享页面列出 og:image:width 和 og:image:height（图片的宽和高，单位像素），并说设置它们有助于图片在第一次被分享时正确加载。图片类型列为 image/jpeg、image/gif 和 image/png。 developers.facebook.com
  • Meta 的页面写明，图片按 URL 缓存，除非 URL 变化否则不会更新。它的 Sharing Debugger 会重新抓取页面，并显示爬虫读取到的 meta 标签，以及发现的错误。 developers.facebook.com
  • Mastodon 文档把预览卡片描述为所链接 URL 的丰富预览，由 OpenGraph 标签生成，含被链接页面的标题、描述和预览缩略图。 docs.joinmastodon.org

大家常问

什么是 Open Graph 图片？

它是页面 og:image 属性里设置的图片，即代表该页面的图片的 URL。Open Graph 协议把 og:title、og:type、og:image 和 og:url 列为页面的四个必填属性。 ogp.me

换了图片，为什么预览还是旧图？

Meta 的页面写明，图片按 URL 缓存，除非 URL 变化否则不会更新。要显示新图片，就要把它发布在新的 URL 下。 developers.facebook.com

链接预览图可以是哪些文件类型？

Meta 的分享页面把 image/jpeg、image/gif 和 image/png 列为 og:image:type 的类型。它还列出以像素计的图片宽和高，并说这有助于图片在第一次被分享时正确加载。 developers.facebook.com

Mastodon 上的链接预览从哪里来？

Mastodon 文档写明，预览卡片由所链接 URL 的 OpenGraph 标签生成，带有被链接页面的标题、描述和预览缩略图。 docs.joinmastodon.org

生成分享图的工具要多少钱？

Bannerbear 的价格页以美元列出每月 US$49、US$149 和 US$299，分别含 1,000、10,000 和 50,000 点数。渲染一张图用 1 个点数，格式越多、缩放越大，用得越多。 bannerbear.com
