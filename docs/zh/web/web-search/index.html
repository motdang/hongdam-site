大家常问

怎样给我的网站加搜索栏？

Pagefind 这类静态站点库会在生成的文件里加入搜索包，搜索在访客的浏览器中运行，不需要托管的搜索服务。 pagefind.app

能用 Google 来搜索我自己的网站吗？

Google 的 Custom Search JSON API 已不再接收新客户。现有客户可在 2027 年 1 月 1 日前迁移，Google 点名 Vertex AI Search 用于搜索最多 50 个域名。 developers.google.com

站内搜索能搜泰文吗？

泰文的词与词之间没有空格，按空格切分会得到错误的词。浏览器提供 Intl.Segmenter，可把泰文等语言切成词，自 2024 年 4 月起各浏览器均可使用。 developer.mozilla.org

托管的站内搜索要多少钱？

Algolia 的免费方案包含每月 10,000 次搜索请求和 50,000 条记录。Grow 方案中，超出的请求每 1,000 次 US$0.50，超出的记录每 1,000 条 US$0.40。 algolia.com
