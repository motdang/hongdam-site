须知

  • 地址在美国以外时，VA.gov 列出两种核验方式：ID.me 或 CLEAR。ID.me 页面上有供不住在美国的人使用的选项，核验方式是与 ID.me 工作人员的视频通话。 va.gov

大家常问

人在海外，怎样通过 ID.me 核验身份？

VA.gov 写明，地址在美国以外时，可以用 ID.me 或 CLEAR。ID.me 的页面上有供不住在美国的人使用的选项。之后 ID.me 会要求在与工作人员的视频通话中出示身份文件。 va.gov

没有美国社会安全号码，可以用 ID.me 吗？

VA.gov 写明，没有美国社会安全号码时，核验身份的途径是 ID.me，所要的文件中有一份是有效的美国护照。 va.gov

持非美国护照的家人可以核验身份吗？

ID.me 的帮助页列出：有效的非美国护照，以及显示海外地址的文件，如银行对账单或水电账单。当事人确认从未获发 SSN 或 ITIN，上传两份文件，然后带着原件参加视频通话。 help.id.me

ID.me 核验走不通怎么办？

ID.me 的帮助页写明，福利被拦下时，要联系的是相关机构本身，因为有些机构可能要求用 SSN 核验身份。 help.id.me

办理 VA 申请的协助要花钱吗？

VA.gov 写明，经认可的 VSO 代表在 VA 福利申请上的服务免费；经认可的律师或理赔代理人可以收费。 va.gov
