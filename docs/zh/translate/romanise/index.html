大家常问

泰文名称怎样写成英文字母？

在泰国提交联合国会议的文件中，皇家学术院的转写法按词的读音书写，不管泰文怎么拼。人名的例子是 Nai Somchai Khonching。 unstats.un.org

英文拼写会标出声调吗？

皇家学术院的转写法不标声调。文件写明，声调符号、含不发音符号在内的附加符号以及元音长短都略去，只写读音。 unstats.un.org

泰国地名怎么写？

文件写明地名不翻译，整个名称适用一般转写规则，如 Ko Si Chang、Thanon Tha Phra。 unstats.un.org

含英文词的公司名称会改写吗？

文件写明，本身是专有名称的外来词按原文书写，如 First Class Co.Ltd.；只是名称一部分的外来词按泰语读音书写。 unstats.un.org
