大家常问

掸语属于哪个语系？

BGN/PCGN 文件称它是缅甸境内使用的一种 Tai（傣泰语支）语言，文字源自缅文。 assets.publishing.service.gov.uk

有多少人说掸语？

BGN/PCGN 文件给出掸邦估计有 320 万人说掸语，数字取自《民族语》（Ethnologue）第 16 版（2009）。 assets.publishing.service.gov.uk

掸语可以在电脑上输入吗？

可以，用 Unicode。其缅甸文区块（U+1000–109F）收有掸文字母、元音符号和声调符号，以及缅文、孟文、克伦文字母。 unicode.org
