须知

  • 主机连不上时，Cloudflare 的 Always Online 提供 Cloudflare 缓存里保存的副本；没有的话，从 Internet Archive 的 Wayback Machine 取静态页面。 developers.cloudflare.com
  • 主机离线时，Always Online 无法提供动态内容。购物车和评论框会显示错误。 developers.cloudflare.com
  • Always Online 适用于 Free、Pro、Business 和 Enterprise 套餐。存档抓取频率：Free 每 30 天一次，Pro 每 15 天一次，Business 和 Enterprise 每 5 天一次。 developers.cloudflare.com
  • Cloudflare Load Balancing 按设定的间隔对每个端点做健康检查。端点不响应、响应太慢，或返回意外的状态码或内容，就算失败。 developers.cloudflare.com
  • 在 Cloudflare Load Balancing 中，低于健康阈值的资源池不再接收流量，流量转到其他资源池。 developers.cloudflare.com

大家常问

主机宕机时，访客会看到什么？

用 Cloudflare Always Online 时，访客看到页面的已保存副本，上面有一条横幅，说明这是存档版本，并带有 Refresh 按钮。页面没有已保存的副本的话，看到的是主机的错误页面。 developers.cloudflare.com

已保存的副本能用于网店或表单吗？

Always Online 做不到。Cloudflare 说，主机离线时它无法提供动态内容，用购物车或评论框的访客会看到错误。 developers.cloudflare.com

负载均衡器怎么知道主机宕机了？

Cloudflare 的监控按设定的间隔发送健康检查请求。每个所选区域从三个数据中心检查，多数区域健康，端点就算健康。 developers.cloudflare.com

存放备份副本的存储要多少钱？

Cloudflare R2 标价每 GB 每月 US$0.015，每月前 10 GB 免费。通过其 API 把数据传出 R2 不收费。 developers.cloudflare.com
