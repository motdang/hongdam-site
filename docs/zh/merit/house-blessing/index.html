须知

  • 新居祈福邀请奇数位僧人，例如5、7或9位。主人先联系寺庙，确认日期和僧人人数。 thailandfoundation.or.th
  • 僧人的午斋在白天举行，约11点开始，12点前结束。上座部僧人过了中午不进食。 thailandfoundation.or.th
  • 顺序：僧人到达并诵经；主人向佛像和僧人供斋；饭后主人可以献上鲜花、香、蜡烛或僧伽布施套装；僧人再次诵经，并用圣水洒净场地。 thailandfoundation.or.th
  • 主人用圣线（sai sin）装饰建筑，并让圣线绕过佛像和僧人的座位。僧人用粉末书写经咒图（yantra），并在重要位置贴金箔，包括前门上或门上方。 thailandfoundation.or.th
  • 在泰国北部，主人还会请一位仪式主持（มัคนายก）来主持整个仪式。企业主也可以为新办公室举行这一仪式。 thailandfoundation.or.th

大家常问

要邀请几位僧人

Thailand Foundation 提到奇数，例如5、7或9位。主人先联系寺庙，确认日期和僧人人数。 thailandfoundation.or.th

仪式按什么顺序进行

僧人到达、就座并诵经。主人向佛像和僧人供斋。饭后，主人可以献上鲜花、香、蜡烛或僧伽布施套装。僧人再次诵经，并用圣水洒净场地。 thailandfoundation.or.th

仪式在一天中的什么时间举行

KTC 提到两个常见时间：早上7:30，或10:30的僧人午斋。 ktc.co.th

需要准备什么

KTC 列出：带佛像的供佛桌、僧伽布施套装、僧人的信封和日用品、放有银箔和金箔的圣水碗、鲜花、香、蜡烛、食物、饮用水，以及供宾客用的席子和椅子。 ktc.co.th

新居祈福要花多少钱

曼谷一户人家2020年为5位僧人和40位宾客预算约฿14,000。餐食和饮料฿8,436，僧人的信封฿3,000，僧伽布施套装฿1,500。 sanook.com

提前多久邀请僧人

KTC 给出的提前期约为一个月。 ktc.co.th

哪一天是好日子

KTC 写道，很多人参考中国历法，例如“ธงไชย”（Thongchai）日。也有人选亲戚方便来的周末。 ktc.co.th

店铺也举行这个仪式吗

Thailand Foundation 提到，企业主可以为新办公室举行这一仪式。 thailandfoundation.or.th
