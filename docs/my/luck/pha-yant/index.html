  • ယန္တရား (yant) သည် ဂျီအိုမက်ထရီပုံစံများ၊ တိရစ္ဆာန်များနှင့် မြင့်မြတ်သောစာလုံးများဖြင့် ဖွဲ့စည်းထားသော ပုံစံဖြစ်သည်။ စကားလုံးသည် သင်္သကရိုက် yantra (မြင့်မြတ်သော ပုံကြမ်း) မှ လာသည်။ ထိုပုံစံများကို အထည်၊ လိပ်ထားသော သတ္တုပြား အကာအကွယ်ပစ္စည်းများနှင့် တံခါးအပေါ်တွင်လည်း တွေ့ရသည်။ visitthailandtoday.com
  • ဤလမ်းညွှန်က ဆရာ (ajarn) ကို ရဟန်းမဟုတ်သော သာမန်လူဆရာ၊ ရဟန်းဟောင်း ဖြစ်လေ့ရှိသူအဖြစ် ဖော်ပြသည်။ ဆရာများသည် ဗိမာန်တစ်ခုတွင် အလုပ်လုပ်ကြသည်။ visitthailandtoday.com
  • ထိုင်းအလယ်ပိုင်းတွင် ယန္တရားကို ခမာအက္ခရာမှ ဆင်းသက်လာသော Khom (ขอม) အက္ခရာဖြင့် ရေးသည်။ မြောက်ပိုင်းထိုင်း ယန္တရားများသည် ရှမ်း၊ မြောက်ပိုင်းထိုင်း သို့မဟုတ် တိုင်လူး အက္ခရာများကို သုံးနိုင်သည်။ en.wikipedia.org

လူများ မေးသည့်မေးခွန်း

ယန္တရားအထည် (pha yant) ဆိုတာ ဘာလဲ။

ယန္တရားသည် မြင့်မြတ်သော ပုံစံတစ်မျိုးဖြစ်ပြီး ယန္တရားအထည်ကတော့ ထိုပုံစံကို အရေပြားအစား အထည်ပေါ်တွင် ထားခြင်းဖြစ်သည်။ လမ်းညွှန်က ထိုပုံစံများသည် အထည်၊ လိပ်ထားသော သတ္တုပြား အကာအကွယ်ပစ္စည်းများနှင့် တံခါးအပေါ်တွင်လည်း တွေ့ရပြီး အရေပြားပေါ်ထိုးခြင်းသည် အကိုယ်ပိုင်ဆုံးပုံစံဟု ဆိုသည်။ visitthailandtoday.com

လူတွေက ဆရာကို ဘာတွေ ပူဇော်ကြသလဲ။

ဝပ်ဘန်ဖရတွင် လူတွေက ပန်း၊ အမွှေးတိုင်နှင့် ဆေးလိပ် ပါသော ပူဇော်ပစ္စည်းအစုံကို ဝယ်ကြပြီး မကြာသေးမီ အစီရင်ခံစာများအရ ဈေးနှုန်းမှာ ฿100–150 ခန့် ဖြစ်သည်။ ဆရာ၏ ဗိမာန်တွင် ပူဇော်ပစ္စည်းကို ဈေးနှုန်းထဲ ထည့်ထားလေ့ရှိသည်။ visitthailandtoday.com

အမျိုးသမီးက ရဟန်းကို ပစ္စည်း လှမ်းပေးလို့ ရသလား။

ထိုင်းနိုင်ငံ ခရီးသွားလာရေးအာဏာပိုင်က အမျိုးသမီးများသည် ရဟန်း သို့မဟုတ် သင်္ကန်းကို မထိရဟု ရေးသားထားသည်။ အမျိုးသမီးက ပစ္စည်းကို အမျိုးသားတစ်ဦးထံ ပေး၍ လွှဲပေးစေနိုင်သည်၊ သို့မဟုတ် ရဟန်းကောက်ယူရန် ချထားနိုင်သည်။ tatnews.org

ဆရာများက ယန္တရားထိုးခြင်းအတွက် ဘယ်လောက် ကောက်သလဲ။

လမ်းညွှန်က ချင်းမိုင်မြို့တွင် တစ်နာရီ ฿2,000–3,500 ဟု ဖော်ပြပြီး ဘန်ကောက်ရှိ ဆရာတစ်ဦးထံ အသေးစား သို့မဟုတ် အလတ်စားဒီဇိုင်း ฿5,400 မှစ၍၊ အကြီးစား ฿9,500 ဖြစ်သည်။ သာမန်လူ ဆရာများသည် ကြိုတင်သဘောတူထားသော ထောင်ပေါင်းများစွာ ကောက်ပြီး ရှုပ်ထွေးသော လက်ရာများမှာ ฿20,000 အထိ ရှိသည်။ visitthailandtoday.com
