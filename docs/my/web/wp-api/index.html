သိထားသင့်သည်

  • WordPress တွင် ပို့စ်များ၊ စာမျက်နှာများ၊ taxonomy များနှင့် အခြား ပါဝင်ပြီးသား ဒေတာအမျိုးအစားများအတွက် endpoint ပါသော REST API ရှိသည်။ အက်ပ်များက ထို endpoint များတွင် JSON ပို့ယူပြီး အကြောင်းအရာကို ရှာဖွေ၊ ပြင်ဆင်၊ ဖန်တီးသည်။ developer.wordpress.org
  • /wp-json/wp/v2/posts သို့ တောင်းဆိုမှုက ပို့စ်များစုကို ပြန်ပေးသည် — မူလတန်ဖိုးများမှာ တစ်မျက်နှာ 10 ခု၊ status publish နှင့် context view ဖြစ်သည်။ developer.wordpress.org
  • WordPress 6.9 တွင် Abilities API ကို ထည့်သွင်းခဲ့သည်။ ၎င်းသည် plugin၊ theme နှင့် core တို့က မိမိတို့လုပ်ဆောင်နိုင်သည်များကို စက်ဖတ်နိုင်သော ပုံစံဖြင့် ဖော်ပြသည့် မှတ်ပုံတင်စာရင်းဖြစ်သည်။ 2025 နိုဝင်ဘာ 10 ရက်စွဲပါ ပို့စ်က ၎င်းကို AI အေးဂျင့်များနှင့် အလိုအလျောက်စနစ်ကိရိယာများအတွက် အခြေခံဟု ခေါ်သည်။ make.wordpress.org
  • Abilities API ၏ REST endpoint များသည် wp-abilities/v1 အောက်တွင်ရှိပြီး show_in_rest ကို true ထားကာ မှတ်ပုံတင်ထားသော ability များအတွက်သာ ရှိသည်။ ပို့စ်က ၎င်းတို့သည် အထောက်အထားစိစစ်ပြီးသူ တစ်ဦး လိုအပ်သည်ဟု ဆိုသည်။ make.wordpress.org

WordPress တွင် API ရှိပြီးသားလား။

ရှိသည်။ WordPress နှင့်အတူ REST API ပါလာသည်။ ပို့စ်များ၊ စာမျက်နှာများ၊ taxonomy များနှင့် အခြား ပါဝင်ပြီးသား ဒေတာအမျိုးအစားများအတွက် endpoint များပေးပြီး JSON ပြန်ပေးသည်။ developer.wordpress.org

WordPress Abilities API ဆိုတာ ဘာလဲ။

၎င်းသည် WordPress 6.9 ရှိ စနစ်တစ်ခုဖြစ်ပြီး plugin၊ theme နှင့် core တို့က မိမိတို့လုပ်ဆောင်သည်များကို စံနှုန်းနှင့် စက်ဖတ်နိုင်သော ပုံစံဖြင့် မှတ်ပုံတင်သည်။ ability တစ်ခုတွင် အညွှန်း၊ ဖော်ပြချက်၊ အမျိုးအစား၊ input နှင့် output schema များ၊ execute callback နှင့် permission callback တို့ လိုအပ်သည်။ make.wordpress.org

အခြားအက်ပ်တစ်ခုက WordPress REST API သို့ ဘယ်လို ဝင်ရောက်သလဲ။

ကွတ်ကီးဖြင့် အထောက်အထားစိစစ်ခြင်းသည် WordPress အတွင်း ဝင်ရောက်ထားသော အသုံးပြုသူအတွက် WordPress ၏ စံနည်းလမ်းဖြစ်သည်။ အခြားအက်ပ်များအတွက် application password များက အထောက်အထားများကို HTTPS ပေါ်တွင် Basic Auth ဖြင့် ပို့သည်။ developer.wordpress.org
