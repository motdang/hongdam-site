Progressive Web App ဆိုတာ ဘာလဲ

ထောက်ပံ့သည့် browser က ထည့်သွင်းရန် ကမ်းလှမ်းသည့် ဝက်ဘ်အက်ပ် ဖြစ်သည်။ ထည့်သွင်းပြီးပါက အက်ပ်သည် စက်ပေါ်တွင် အိုင်ကွန်ရပြီး browser ခလုတ်များမပါဘဲ သီးခြားအက်ပ်အဖြစ် ဖွင့်နိုင်သည်။ web app manifest နှင့် https လိပ်စာ လိုအပ်သည်။ developer.mozilla.org
