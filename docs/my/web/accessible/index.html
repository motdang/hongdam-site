သိထားသင့်သည်

  • WCAG 2.2 (W3C ၏ Web Content Accessibility Guidelines) သည် နောက်ဆုံးဗားရှင်းဖြစ်ပြီး 2023 အောက်တိုဘာ 5 တွင် ထုတ်ပြန်ကာ 2024 ဒီဇင်ဘာ 12 တွင် ပြင်ဆင်သည်။ စမ်းသပ်နိုင်သော စံနှုန်းများကို A၊ AA နှင့် AAA ဟူ၍ အဆင့်သုံးခု ခွဲထားသည်။ WCAG 2.0 နှင့် 2.1 တို့လည်း အသုံးပြုနိုင်သော စံနှုန်းများအဖြစ် ရှိနေဆဲဖြစ်သည်။ w3.org
  • WCAG သည် စာသားနှင့် နောက်ခံအကြား အရောင်ကွာခြားမှုအချိုး အနည်းဆုံး 4.5:1 နှင့် စာလုံးကြီးအတွက် 3:1 ကို သတ်မှတ်သည်။ စာလုံးကြီးဆိုသည်မှာ 18 point သို့မဟုတ် 14 point ထူ ဖြစ်ပြီး pixel ခန့် 24 နှင့် 18.5 ဖြစ်သည်။ w3.org
  • WCAG သည် အထောက်အကူပြုနည်းပညာ မသုံးဘဲ စာသားကို 200 ရာခိုင်နှုန်းအထိ ချဲ့နိုင်ပြီး အကြောင်းအရာ သို့မဟုတ် လုပ်ဆောင်ချက် မပျောက်ရန် သတ်မှတ်သည်။ ဘရောက်ဇာ zoom သည် ထိုနည်းလမ်းတစ်ခု ဖြစ်သည်။ w3.org
  • WCAG သည် ပုံများနှင့် စာမဟုတ်သော အကြောင်းအရာများတွင် ရည်ရွယ်ချက်တူသော စာသားအစားထိုးချက် ရှိရန် သတ်မှတ်သည်။ အလှဆင်ရုံသက်သက်ဖြစ်သော အရာများကို အထောက်အကူပြုနည်းပညာမှ ဖျောက်ထားသည်၊ ထိုအရာများပေါ်ရှိ အစားထိုးစာသားက screen reader သုံးသူများကို နှောင့်ယှက်သောကြောင့် ဖြစ်သည်။ w3.org
  • Lighthouse သည် ခလုတ်နှင့် လင့်ခ်အမည်များ၊ ARIA attribute များ၊ အရောင်ကွာခြားမှု၊ ပုံ alt စာသား၊ ဖောင်အညွှန်းများ၊ ခေါင်းစဉ်အစီအစဉ်နှင့် စာမျက်နှာဘာသာစကား ကဲ့သို့ အောင်/ကျ စစ်ဆေးမှုများ၏ အလေးပေးပျမ်းမျှဖြင့် accessibility ကို ရမှတ်ပေးသည်။ လက်ဖြင့် စစ်ဆေးမှုများသည် ရမှတ်တွင် မပါပါ။ developer.chrome.com
