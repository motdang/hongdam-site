သိထားသင့်သည်

  • Open Graph protocol သည် စာမျက်နှာတစ်ခုအတွက် မဖြစ်မနေ property လေးခုကို ဖော်ပြသည်။ og:title၊ og:type၊ og:image နှင့် og:url တို့ဖြစ်သည်။ og:image သည် စာမျက်နှာကို ကိုယ်စားပြုသော ပုံ၏ URL ဖြစ်သည်။ og:image:alt မှာ ပုံကို ဖော်ပြသော တွဲဖက် property ဖြစ်သည်။ ogp.me
  • Meta ၏ မျှဝေမှုစာမျက်နှာတွင် og:image:width နှင့် og:image:height (ပုံ၏ အကျယ်နှင့် အမြင့်၊ pixel ဖြင့်) ကို ဖော်ပြပြီး ၎င်းတို့ကို သတ်မှတ်ခြင်းက ပုံကို ပထမဆုံး မျှဝေချိန်မှာပင် မှန်ကန်စွာ တင်နိုင်စေသည်ဟု ဆိုသည်။ ပုံအမျိုးအစားများအဖြစ် image/jpeg၊ image/gif နှင့် image/png ကို ဖော်ပြသည်။ developers.facebook.com
  • Meta ၏ စာမျက်နှာတွင် ပုံများကို URL အလိုက် cache လုပ်ထားပြီး URL မပြောင်းလျှင် မပြောင်းလဲဟု ဆိုသည်။ ၎င်း၏ Sharing Debugger သည် စာမျက်နှာကို ပြန်ဖတ်စေပြီး crawler ဖတ်သော meta tag များကို တွေ့ရှိသော အမှားများနှင့်တကွ ပြသသည်။ developers.facebook.com
  • Mastodon ၏ စာတမ်းတွင် preview card ကို လင့်ခ်ချိတ်ထားသော URL ၏ ကြိုတင်ကြည့်ရှုမှုအဖြစ် ဖော်ပြပြီး OpenGraph tag များဖြင့် ဖန်တီးကာ လင့်ခ်ထားသော စာမျက်နှာ၏ ခေါင်းစဉ်၊ ဖော်ပြချက်နှင့် thumbnail ပါဝင်သည်ဟု ဆိုသည်။ docs.joinmastodon.org

လူများ မေးသည့်မေးခွန်း

Open Graph image ဆိုတာ ဘာလဲ။

၎င်းသည် စာမျက်နှာ၏ og:image property တွင် သတ်မှတ်ထားသော ပုံဖြစ်ပြီး စာမျက်နှာကို ကိုယ်စားပြုသော ပုံ၏ URL ဖြစ်သည်။ Open Graph protocol သည် og:title၊ og:type၊ og:image နှင့် og:url ကို စာမျက်နှာတစ်ခုအတွက် မဖြစ်မနေ property လေးခုအဖြစ် ဖော်ပြသည်။ ogp.me

ပုံပြောင်းပြီးနောက် ကြိုတင်ကြည့်ပုံဟောင်း ဘာကြောင့် ကျန်နေသလဲ။

Meta ၏ စာမျက်နှာတွင် ပုံများကို URL အလိုက် cache လုပ်ထားပြီး URL မပြောင်းလျှင် မပြောင်းလဲဟု ဆိုသည်။ ပုံအသစ်ပြရန် ထိုပုံကို URL အသစ်အောက်တွင် ထုတ်ပြန်ရသည်။ developers.facebook.com

လင့်ခ်ကြိုတင်ကြည့်ပုံသည် ဖိုင်အမျိုးအစား ဘာတွေ ဖြစ်နိုင်သလဲ။

Meta ၏ မျှဝေမှုစာမျက်နှာတွင် og:image:type အတွက် image/jpeg၊ image/gif နှင့် image/png ကို ဖော်ပြသည်။ ပုံ၏ အကျယ်နှင့် အမြင့်ကို pixel ဖြင့်လည်း ဖော်ပြပြီး ၎င်းတို့က ပုံကို ပထမဆုံး မျှဝေချိန်မှာပင် မှန်ကန်စွာ တင်နိုင်စေသည်ဟု ဆိုသည်။ developers.facebook.com

Mastodon လင့်ခ်ကြိုတင်ကြည့်ရှုမှုသည် ဘယ်ကလာသလဲ။

Mastodon ၏ စာတမ်းတွင် preview card ကို လင့်ခ်ချိတ်ထားသော URL ၏ OpenGraph tag များဖြင့် ဖန်တီးသည်ဟု ဆိုသည်။ ၎င်းတွင် လင့်ခ်ထားသော စာမျက်နှာ၏ ခေါင်းစဉ်၊ ဖော်ပြချက်နှင့် thumbnail ပါသည်။ docs.joinmastodon.org
