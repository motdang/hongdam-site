သိထားသင့်သည်

  • Cloudflare သည် ဒိုမိန်း၏ ရှိပြီးသား DNS မှတ်တမ်းများကို ရှာဖွေထည့်ပေးနိုင်သည်။ သို့သော် အားလုံးကို တွေ့မည်ဟု အာမမခံကြောင်း၊ ဒိုမိန်းကိုယ်တိုင်၊ www နှင့် အီးမေးလ် မှတ်တမ်းများကို ပြန်စစ်ရမည်ဟု ၎င်း၏ စာမျက်နှာက ဆိုသည်။ developers.cloudflare.com
  • မှတ်ပုံတင်သူက nameserver များကို အပ်ဒိတ်လုပ်နေစဉ် ၂၄ နာရီအထိ စောင့်ရန် Cloudflare ၏ စာမျက်နှာက ဆိုသည်။ developers.cloudflare.com
  • nameserver မပြောင်းမီ မှတ်ပုံတင်သူထံတွင် DNSSEC ကို ပိတ်ရမည်ဟု Cloudflare ကဆိုသည်။ ဖွင့်ထားစဉ် ပြောင်းလျှင် ဒိုမိန်းကို ဝင်မရနိုင်ပါ။ developers.cloudflare.com
  • Cloudflare အစီအစဉ်တိုင်းတွင် ဒိုမိန်းကိုယ်တိုင် (www မပါသော yourshop.com) ပေါ်ရှိ CNAME မှတ်တမ်းကို မူလအတိုင်း flatten လုပ်ပေးသဖြင့် အခြား DNS ဝန်ဆောင်မှုများ လက်မခံသည့်နေရာတွင်ပင် အလုပ်လုပ်သည်။ developers.cloudflare.com
  • Free အစီအစဉ်ရှိ Cloudflare Email Routing သည် ဒိုမိန်းပေါ်ရှိ လိပ်စာများသို့ ဝင်လာသော မေးလ်ကို သင်သုံးနေသော inbox သို့ ပို့ပေးသည်။ ဝင်လာသော မေးလ်အတွက်သာ ဖြစ်သည်။ developers.cloudflare.com
