လူများ မေးသည့်မေးခွန်း

ဝက်ဘ်ဆိုက်အတွက် အခမဲ့ ရာသီဥတု ဝစ်ဂျက် ရှိပါသလား။

Open-Meteo ၏ ရာသီဥတု API သည် စီးပွားဖြစ်မဟုတ်သော အသုံးပြုမှုအတွက် တစ်ရက် 10,000 ကြိမ်အထိ အခမဲ့ဖြစ်သည်။ ပိုက်ဆံပေးအစီအစဉ်များသည် စီးပွားဖြစ်အသုံးပြုမှုကို လွှမ်းခြုံပြီး တစ်လ 1 သန်းကြိမ်မှ စသည်။ open-meteo.com

အကွက်က ကျွန်ုပ်မြို့၏ PM2.5 ကို ပြနိုင်ပါသလား။

Open-Meteo သည် PM2.5 ကို တစ်နာရီချင်း လေထုအရည်အသွေး ကိန်းရှင်များထဲတွင် ဖော်ပြထားပြီး US AQI နှင့် European AQI လည်း ပါသည်။ ကမ္ဘာလုံးဆိုင်ရာ ခန့်မှန်းချက်သည် 0.4°၊ ခန့်မှန်း 45 ကီလိုမီတာ ဂရစ်ပေါ်တွင် ရှိသည်။ open-meteo.com

အကွက်က ဧည့်သည်၏ တည်နေရာကို ကိုယ်တိုင် ရှာနိုင်ပါသလား။

စာမျက်နှာတစ်ခုသည် လုံခြုံသော ပတ်ဝန်းကျင် (HTTPS) တွင်သာ ဧည့်သည်၏ တည်နေရာကို ဖတ်နိုင်သည်။ ဘရောက်ဇာက ဧည့်သည်ထံ ခွင့်ပြုချက်ကို အရင်တောင်းသည်။ developer.mozilla.org
