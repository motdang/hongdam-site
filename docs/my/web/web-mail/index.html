သိထားသင့်သည်

  • Google Workspace ၏ မေးလ်မှတ်တမ်းသည် MX တန်ဖိုး smtp.google.com ကို priority 1 ဖြင့် သုံးသည် (MX မှတ်တမ်းဆိုသည်မှာ ဒိုမိန်း၏ မေးလ်ကို ဘယ်ကိုပို့ရမည်ဟု ပြောသော ဆက်တင်လိုင်းဖြစ်သည်)။ Google ၏ စာမျက်နှာတွင် MX မှတ်တမ်းအသစ်ကို အသိအမှတ်ပြုရန် 72 နာရီအထိ ကြာနိုင်ပြီး အခြား MX မှတ်တမ်းများကို ဖယ်ရှားရမည့် အဆင့်ကိုလည်း ဖော်ပြထားသည်။ knowledge.workspace.google.com
  • Microsoft 365 သည် ကိုယ်ပိုင်ဒိုမိန်း၏ မေးလ်အတွက် MX မှတ်တမ်း လိုအပ်သည်။ Autodiscover CNAME မှတ်တမ်းနှင့် SPF TXT မှတ်တမ်းတို့မှာ ရွေးချယ်စရာဖြစ်ပြီး Microsoft ၏ စာမျက်နှာက အထူးအကြံပြုသည်ဟု ဆိုသည်။ MX မှတ်တမ်း ပြောင်းလိုက်သောအခါ ဒိုမိန်း၏ မေးလ်အသစ်အားလုံး Microsoft 365 သို့ ရောက်ပြီး ရှိပြီးသားမေးလ်များမှာ မရွှေ့လျှင် ယခင်ဝန်ဆောင်မှုပေးသူထံတွင်သာ ကျန်သည်။ learn.microsoft.com
  • Gmail သည် ပို့သူအားလုံးအတွက် SPF သို့မဟုတ် DKIM လိုအပ်သည်။ Gmail အကောင့်များသို့ တစ်နေ့ 5,000 ကျော် ပို့သူများအတွက် SPF၊ DKIM နှင့် DMARC လိုသည် (ဤသုံးခုမှာ မက်ဆေ့ချ်သည် ၎င်းဖော်ပြသည့် ဒိုမိန်းမှ လာကြောင်း ပြသသည့် မှတ်တမ်းများဖြစ်သည်)။ DMARC policy ကို none ဟု သတ်မှတ်နိုင်သည်။ support.google.com
  • Cloudflare Email Routing သည် ဒိုမိန်းပေါ်ရှိ လိပ်စာသို့ ဝင်လာသော မေးလ်ကို အခြားနေရာသို့ လွှဲပို့ပေးသည်။ မေးလ်ကို မပို့ပါ၊ ပို့ခြင်းသည် Cloudflare ၏ သီးခြားထုတ်ကုန်ဖြစ်သည်။ developers.cloudflare.com

ထိုင်းနိုင်ငံတွင် Google Workspace ဈေး ဘယ်လောက်လဲ။

Google ၏ ထိုင်းဘာသာ ဈေးနှုန်းစာမျက်နှာတွင် Starter ကို အသုံးပြုသူတစ်ဦးလျှင် တစ်လ ฿275၊ Standard ฿550၊ Plus ฿850 (အခွန်မပါ) ဟု ဖော်ပြသည်။ ဖောက်သည်အသစ်များအတွက် ပထမအသုံးပြုသူ 20 ဦး၊ ပထမ 12 လတွင် Starter ฿137.50၊ Standard ฿330 ဟု ပြထားသည်။ workspace.google.com

ကိုယ်ပိုင်ဒိုမိန်းအီးမေးလ်ကို အခမဲ့ ရနိုင်သလား။

Cloudflare Email Routing ကို Cloudflare ၏ အခမဲ့အစီအစဉ်တွင် ရရှိနိုင်သည်။ ဒိုမိန်းလိပ်စာသို့ ဝင်လာသော မေးလ်ကို အခြားနေရာသို့ လွှဲပို့ပေးပြီး မေးလ်မပို့ပါ။ ပို့ခြင်းမှာ သီးခြားထုတ်ကုန်ဖြစ်ပြီး Workers Paid အစီအစဉ်တွင် beta အဆင့်ရှိသည်။ developers.cloudflare.com

MX မှတ်တမ်း ပြောင်းပြီးနောက် မေးလ် ဘယ်အချိန် ရောက်မလဲ။

Google ၏ စာမျက်နှာတွင် MX မှတ်တမ်းအသစ်ကို အသိအမှတ်ပြုရန် 72 နာရီအထိ ကြာနိုင်သည်ဟု ဆိုသည်။ Admin console ရှိ Gmail ဖွင့်သည့်အဆင့်ကိုလည်း ပြီးမှ မေးလ် စီးဝင်နိုင်ကြောင်း ထပ်ပြောသည်။ knowledge.workspace.google.com

Gmail က ပို့သည့်ဒိုမိန်းထံမှ ဘယ်မှတ်တမ်းတွေ တောင်းသလဲ။

Gmail က ပို့သူအားလုံးထံမှ SPF သို့မဟုတ် DKIM တောင်းသည်။ Gmail အကောင့်များသို့ တစ်နေ့ 5,000 ကျော် ပို့သူများက SPF၊ DKIM နှင့် DMARC လိုသည်။ ထိုစာမျက်နှာတွင် Postmaster Tools ၌ စပမ်းနှုန်း 0.3% အောက်ရှိရန်လည်း ဖော်ပြသည်။ support.google.com

Outlook နှင့် Microsoft 365 ကို ကိုယ်ပိုင်ဒိုမိန်း မေးလ်အတွက် သုံးနိုင်သလား။

သုံးနိုင်သည်။ Microsoft ၏ စာမျက်နှာတွင် အခြားနေရာမှ ဝယ်ထားသော ဒိုမိန်းကို registrar ၌ DNS မှတ်တမ်းများ ထည့်၍ ချိတ်ဆက်ပုံ ရှင်းပြထားပြီး ဒိုမိန်းသည် ထိုနေရာတွင်ပင် မှတ်ပုံတင်ထားဆဲ ဖြစ်သည်။ ကိုယ်ပိုင်ဒိုမိန်း မထည့်လျှင် onmicrosoft.com လိပ်စာကို သုံးရသည်။ learn.microsoft.com
