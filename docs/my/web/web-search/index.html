သိထားသင့်သည်

  • ထိုင်း၊ တရုတ်၊ ဂျပန်၊ လာအို၊ ခမာနှင့် မြန်မာစာတို့တွင် စကားလုံးကြားတွင် နေရာလွတ် မခြားပါ။ ထို့ကြောင့် နေရာလွတ်ဖြင့် ဖြတ်ပါက စကားလုံး မှားသွားသည်။ ဘရောက်ဇာများတွင် ထိုစာသားကို စကားလုံးခွဲရန် Intl.Segmenter ရှိပြီး 2024 ဧပြီလမှစ၍ ဘရောက်ဇာအများအပြားတွင် သုံးနိုင်သည်။ developer.mozilla.org
  • Google ၏ Custom Search JSON API သည် ဖောက်သည်အသစ်များအတွက် ပိတ်ထားပြီး လက်ရှိဖောက်သည်များက အခြားနည်းလမ်းသို့ ပြောင်းရန် 2027 ဇန်နဝါရီ 1 အထိ အချိန်ရှိသည်။ Google က Vertex AI Search ကို ဒိုမိန်း 50 အထိ ရှာဖွေရန် အခြားရွေးချယ်စရာအဖြစ် ဖော်ပြသည်။ developers.google.com
  • Pagefind သည် လွတ်လပ်သော open-source ရှာဖွေရေး စာကြည့်တိုက်တစ်ခုဖြစ်ပြီး static HTML ထုတ်ကုန် မည်သည့်အမျိုးအစားနှင့်မဆို အလုပ်လုပ်ကာ တည်ဆောက်ပြီးသော ဖိုင်များထဲသို့ static ရှာဖွေရေးအစုအဝေးတစ်ခု ထည့်ပေးသည်။ ဘာသာစကားစုံ ဝက်ဘ်ဆိုက်များကို ပြင်ဆင်ရန်မလိုဘဲ ပံ့ပိုးကြောင်း ဖော်ပြပြီး ဆာဗာကဲ့သို့ အခြေခံအဆောက်အအုံ ကိုယ်တိုင် မထားဘဲ အလုပ်လုပ်သည်။ pagefind.app
