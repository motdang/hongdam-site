သိထားသင့်သည်

  • W3C က စာမျက်နှာရှိ စာသား၏ မူလဘာသာစကားကို ကြေညာရန် html tag တွင် ဘာသာစကား attribute ထည့်ရန် ဆိုသည်၊ အခြား element များက ၎င်းကို အမွေဆက်ခံပြီး ဘာသာစကားစုံပါသော အကြောင်းအရာတွင် ၎င်းကို ဝန်းရံထားသော element ပေါ်၌ သီးခြား attribute ထည့်သည်။ w3.org
  • Google က စာမျက်နှာ၏ ဘာသာစကားကို သိရန် hreflang သို့မဟုတ် HTML lang attribute ကို မသုံးဘဲ ၎င်း၏ အယ်လဂိုရီသမ်များကို သုံးသည်ဟု ဆိုသည်။ developers.google.com

  • Fastwork ရှိ ထိုင်းစာစစ်သူတစ်ဦးက စစ်ဆေးမှုကို စာလုံးပေါင်းမှားသောစကားလုံး၊ နေရာခြားမှုနှင့် အမှတ်အသားများသာ ကန့်သတ်ပြီး ထိုင်းဘာသာမူရင်းကိုသာ လက်ခံသည်။ fastwork.co

လူများ မေးသည့်မေးခွန်း

ထိုင်းတွင် စာစစ်ခ ဘယ်လောက်လဲ။

Fastwork ရောင်းသူတစ်ဦးက ထိုင်းစာကို A4 စာမျက်နှာ (ဖောင့် 16) တစ်မျက်နှာ ฿10 နှင့် A5 တစ်မျက်နှာ ฿5 ဖြင့် စစ်ဆေးပေးသည်။ စာလုံးပေါင်းမှားသောစကားလုံး၊ နေရာခြားမှုနှင့် အမှတ်အသားများကို စစ်သည်။ fastwork.co

စာမျက်နှာကို ထိုင်း သို့မဟုတ် အင်္ဂလိပ်ဟု ဘယ်လိုအမှတ်အသားပြုရမလဲ။

W3C က html tag တွင် ဘာသာစကား attribute ထည့်ရန် ဆိုသည်၊ အင်္ဂလိပ်အတွက် <html lang="en"> ကဲ့သို့။ အခြား element များက ၎င်းကို အမွေဆက်ခံပြီး အခြားဘာသာစကားဖြင့်ရေးသော အကြောင်းအရာတွင် ကိုယ်ပိုင် attribute ထည့်သည်။ ဘာသာစကား subtag များသည် IANA Language Subtag Registry မှ လာသည်။ w3.org

Google က စာမျက်နှာ၏ lang attribute ကို ဖတ်ပါသလား။

စာမျက်နှာ၏ ဘာသာစကားကို သိရန် Google သည် hreflang သို့မဟုတ် HTML lang attribute ကို မသုံးဘဲ အယ်လဂိုရီသမ်ကို သုံးသည်ဟု ဆိုသည်။ hreflang ကိုမူ စာမျက်နှာကို ၎င်း၏ ဒေသဆိုင်ရာ ဗားရှင်းများနှင့် တွဲရန် သုံးသည်။ developers.google.com

စာစစ်ခြင်းက ကျွန်ုပ်၏ စာသားကို ပြန်ရေးပေးပါသလား။

Fastwork ရှိ အင်္ဂလိပ်စာစစ်သူတစ်ဦးက မှတ်ချက်နှင့် အကြံပြုချက်များ ပေးပြီး စာသားကို ပြန်ရေးခြင်း၊ ပြောင်းရေးခြင်း မလုပ်ပေးဟု ဖော်ပြထားသည်။ fastwork.co
