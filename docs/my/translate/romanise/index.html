သိထားသင့်သည်

  • ထိုင်းနိုင်ငံက ကုလသမဂ္ဂ ပထဝီအမည်စံသတ်မှတ်ရေး ညီလာခံသို့ တင်သွင်းသော စာတမ်းတွင် Royal Institute ၏ အသံလိုက်ရေးနည်း (transcription) သည် မူလစာလုံးပေါင်းကို မထည့်သွင်းဘဲ ထိုင်းစကားလုံးများ၏ အသံကို ရေးသည်၊ အသံနေအသံထားမှတ်၊ အသံမထွက်မှတ်နှင့် သရရှည်တိုကို မဖော်ပြပါ။ unstats.un.org
  • ထိုစာတမ်းတွင် ပထဝီအမည်များကို မဘာသာပြန်ဟု ဆိုသည်၊ Ko Si Chang (Si Chang Island မဟုတ်)၊ Maenam Pa Sak (Pa Sak River မဟုတ်)၊ Thanon Tha Phra (Tha Phra Road မဟုတ်)။ unstats.un.org
  • ကိုယ်ပိုင်အမည်ဖြစ်သော ချေးယူစကားလုံးကို မူရင်းအတိုင်း ရေးသည်၊ ဥပမာ First Class Co.Ltd.။ အမည်၏ တစ်စိတ်တစ်ပိုင်းသာဖြစ်သော ချေးယူစကားလုံးကို ထိုင်းအသံထွက်အတိုင်း ရေးသည်။ unstats.un.org
  • စာတမ်းထဲက ဥပမာများတွင် လူအမည်အတွက် Nai Somchai Khonching၊ ဘုရားကျောင်းအတွက် Wat Duang Khae နှင့် ကျောင်းအတွက် Rongrian Sattri Witthaya တို့ ပါသည်။ unstats.un.org

လူများ မေးသည့်မေးခွန်း

ထိုင်းအမည်များကို အင်္ဂလိပ်အက္ခရာဖြင့် ဘယ်လိုရေးသလဲ။

ထိုင်းနိုင်ငံက ကုလသမဂ္ဂ ညီလာခံသို့ တင်သွင်းသော စာတမ်းတွင် Royal Institute ၏ အသံလိုက်ရေးနည်းသည် ထိုင်းစာလုံးပေါင်း မည်သို့ပင်ဖြစ်စေ စကားလုံး၏ အသံထွက်အတိုင်း ရေးသည်။ လူအမည်ဥပမာမှာ Nai Somchai Khonching ဖြစ်သည်။ unstats.un.org

အင်္ဂလိပ်စာလုံးပေါင်းတွင် အသံနေအသံထားမှတ်များ ပါပါသလား။

Royal Institute ၏ အသံလိုက်ရေးနည်းတွင် မပါပါ။ စာတမ်းတွင် အသံနေအသံထားမှတ်၊ အသံမထွက်မှတ်အပါအဝင် အမှတ်အသားများနှင့် သရရှည်တိုတို့ကို လျစ်လျူရှုသည်၊ အသံကိုသာ ရေးသည်ဟု ဆိုသည်။ unstats.un.org

ထိုင်းနေရာအမည်များကို ဘယ်လိုရေးသလဲ။

စာတမ်းတွင် ပထဝီအမည်များကို မဘာသာပြန်ဘဲ အမည်တစ်ခုလုံးတွင် ယေဘုယျ အသံလိုက်ရေးနည်းစည်းမျဉ်းများကို သုံးသည်ဟု ဆိုသည်၊ ဥပမာ Ko Si Chang နှင့် Thanon Tha Phra။ unstats.un.org

အင်္ဂလိပ်စကားလုံးပါသော ကုမ္ပဏီအမည်များကို ပြောင်းပါသလား။

စာတမ်းတွင် ကိုယ်ပိုင်အမည်ဖြစ်သော ချေးယူစကားလုံးကို မူရင်းအတိုင်း ရေးသည်ဟု ဆိုသည်၊ ဥပမာ First Class Co.Ltd.။ အမည်၏ တစ်စိတ်တစ်ပိုင်းသာဖြစ်သော ချေးယူစကားလုံးကို ထိုင်းအသံထွက်အတိုင်း ရေးသည်။ unstats.un.org
