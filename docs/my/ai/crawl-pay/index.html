သိထားသင့်သည်

  • Cloudflare ၏ pay per crawl သည် ပိတ်ထားသော beta တွင် ရှိသည်။ စာမျက်နှာက စာရင်းသွင်းရန်စာမျက်နှာသို့ ညွှန်ပြပြီး Enterprise ဖောက်သည်များသည် ၎င်းတို့၏ အကောင့်မန်နေဂျာကို ဆက်သွယ်နိုင်သည်။ developers.cloudflare.com
  • မပေးချေသော crawler သည် စျေးနှုန်းပါသော HTTP 402 Payment Required (ငွေပေးချေရန် လိုသည်) အဖြေကို ရသည်။ တောင်းဆိုမှု header တွင် ပေးချေလိုကြောင်း ပို့သော crawler သည် ပုံမှန်အဖြေ HTTP 200 ကို ရသည်။ developers.cloudflare.com
  • စျေးနှုန်းကို ဆိုက်ပိုင်ရှင်က သတ်မှတ်သည်။ Cloudflare ဆောင်းပါးက ဆိုက်တစ်ခုလုံးအတွက် တောင်းဆိုမှုတစ်ခုလျှင် စျေးတစ်မျိုးတည်းကို ဖော်ပြပြီး ပိုင်ရှင်သည် ရွေးထားသော crawler များကို အခမဲ့ ဝင်ခွင့်ပြုနိုင်သည်။ blog.cloudflare.com
  • Cloudflare သည် pay per crawl အတွက် Merchant of Record (ငွေလက်ခံသော တရားဝင်ရောင်းသူ) အဖြစ် ဆောင်ရွက်သည်။ crawler တစ်ခုကို ပိတ်ဆို့သော WAF သို့မဟုတ် Bot Management စည်းမျဉ်းသည် ငွေကောက်ခံမှုကို ကျော်လွန်သဖြင့် ထို crawler မဝင်နိုင်ပါ။ developers.cloudflare.com
  • Cloudflare ၏ AI Crawl Control သည် မည်သည့် AI ဝန်ဆောင်မှုများ ဆိုက်ကို ဝင်ရောက်သည်ကို ပြပြီး crawler တစ်ခုချင်းစီအတွက် ခွင့်ပြု သို့မဟုတ် ပိတ်ဆို့စည်းမျဉ်း သတ်မှတ်ကာ robots.txt လိုက်နာမှုကို စောင့်ကြည့်သည်။ Cloudflare အစီအစဉ်အားလုံးတွင် အလုပ်လုပ်သည်။ developers.cloudflare.com

မည်သူမဆို pay per crawl သုံးနိုင်သလား။

မရသေးပါ။ Cloudflare က ၎င်းကို ပိတ်ထားသော beta ဟု ဖော်ပြသည်။ ဆိုက်ပိုင်ရှင်များနှင့် crawler လုပ်ကိုင်သူများသည် Cloudflare ၏ pay per crawl စာရင်းသွင်းစာမျက်နှာမှ စာရင်းသွင်းပြီး Enterprise ဖောက်သည်များသည် ၎င်းတို့၏ အကောင့်မန်နေဂျာကို ဆက်သွယ်နိုင်သည်။ developers.cloudflare.com

ဆိုက်ပိုင်ရှင်သည် ဘော့တစ်ခုချင်းစီအတွက် ဘာတွေ ရွေးနိုင်သလဲ။

သုံးမျိုး။ ခွင့်ပြုခြင်းသည် အခမဲ့ ဝင်ခွင့်ပေးသည်။ ငွေကောက်ခြင်းသည် ဒိုမိန်းတစ်ခုလုံးအတွက် သတ်မှတ်ထားသော စျေးကို တောင်းပြီး Cloudflare နှင့် ငွေကောက်ခံရေး ဆက်ဆံရေး မရှိသေးသော crawler အတွက်ပင် အလုပ်လုပ်သည်။ ပိတ်ဆို့ခြင်းသည် ငွေပေးချေခွင့်မရှိဘဲ ဝင်ခွင့်ကို ငြင်းပယ်သည်။ blog.cloudflare.com

ကျွန်ုပ်၏ robots.txt ကို ဘော့ဘယ်ဟာတွေ လိုက်နာသည်ကို ဘယ်လိုကြည့်နိုင်သလဲ။

Cloudflare ၏ AI Crawl Control တွင် crawler လှုပ်ရှားမှု dashboard ရှိပြီး robots.txt လိုက်နာမှုကို စောင့်ကြည့်သည်။ မည်သည့် crawler များ ညွှန်ကြားချက်ကို လိုက်နာသည်ကို ပြပြီး ၎င်းတို့ကို အတင်းလိုက်နာစေရန် စည်းမျဉ်းများ ဖန်တီးနိုင်သည်။ Cloudflare အစီအစဉ်အားလုံးတွင် အလုပ်လုပ်သည်ဟု စာမျက်နှာက ဖော်ပြသည်။ developers.cloudflare.com
