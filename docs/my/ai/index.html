သိထားသင့်သည်

  • Zapier (အလိုအလျောက်လုပ်ငန်းစဉ် ဝန်ဆောင်မှု) သည် အောင်မြင်သော လုပ်ဆောင်ချက်အဆင့်များကိုသာ task အဖြစ် ရေတွက်သည်; trigger များ မပါ။ help.zapier.com
  • n8n လိုင်စင်က ဆော့ဖ်ဝဲကို အခမဲ့နှင့် စီးပွားရေးမဟုတ်သော အသုံးအတွက်သာ အခြားသူထံ ပေးခွင့်ပြုသည်။ github.com
  • Cloudflare ၏ pay per crawl (စာမျက်နှာ ဖတ်သည့် ဘော့များကို ငွေကောက်ခြင်း) သည် အချို့အသုံးပြုသူများသာ သုံးနိုင်သော စမ်းသပ်ဆဲ အဆင့်တွင်ရှိသည်။ မပေးသော ဘော့သည် စျေးနှုန်းနှင့်အတူ HTTP 402 အမှား (ငွေပေးရန်လိုသည်) ရသည်။ developers.cloudflare.com

အခြားသူများ ကောက်ခံသော စျေးနှုန်း
