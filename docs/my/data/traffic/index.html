လူများ မေးသည့်မေးခွန်း

verified bot ဆိုတာ ဘာလဲ။

Cloudflare က verified bot ကို မိမိသည် မည်သူဖြစ်ပြီး ဘာလုပ်သည်ကို ပွင့်ပွင့်လင်းလင်း ပြောသည်ဟု Cloudflare က အတည်ပြုထားသော ဘော့ သို့မဟုတ် အေးဂျင့်ဟု ခေါ်သည်။ ဥပမာများမှာ ရှာဖွေရေးအင်ဂျင် crawler များ၊ စောင့်ကြည့်ရေးဝန်ဆောင်မှုများနှင့် အသုံးပြုသူ ညွှန်ကြားသော အေးဂျင့်များ ဖြစ်သည်။ developers.cloudflare.com

Google Analytics က ဘော့များကို ရေတွက်ပါသလား။

Google Analytics က သိရှိပြီးသား ဘော့များနှင့် spider များမှ ထရက်ဖစ်ကို အလိုအလျောက် ဖယ်ထားသည်။ Google စာမျက်နှာက ဤဖယ်ထုတ်မှုကို ပိတ်၍မရဟု ဆိုပြီး ဖယ်ထုတ်ခဲ့သော ဘော့ထရက်ဖစ် ပမာဏကိုလည်း မမြင်ရဟု ဆိုသည်။ support.google.com

Cloudflare ပေါ်မှာ မရှိသော ဝဘ်ဆိုက်တစ်ခုရဲ့ ဝင်ကြည့်မှုကို ရေတွက်နိုင်ပါသလား။

နိုင်သည်။ Cloudflare ၏ Web Analytics ဆက်တင်စာမျက်နှာတွင် ဝဘ်ဆိုက်ကို hostname ဖြင့် ထည့်ပြီး ရလာသော JavaScript ကုဒ်ကို ဝဘ်ဆိုက်၏ HTML စာမျက်နှာများတွင် ပိတ်သည့် body tag မတိုင်မီ ထည့်ရသည်။ developers.cloudflare.com
