Taejai.com (เทใจ) သည် ထိုင်းလူထုအတွက် လှူဒါန်းရေးအသိုင်းအဝိုင်း ဖြစ်သည်။ လူ့အဖွဲ့အစည်းကောင်းမွန်ရေး စီမံကိန်းရှိသူတိုင်း အွန်လိုင်းဖောင်ဖြင့် တင်သွင်းနိုင်ပြီး လှူဒါန်းသူများက စီမံကိန်းများကို လှူဒါန်းကြသည်။ ပင်မစာမျက်နှာတွင် လှူဒါန်းသူ 231,579 ဦးမှ ฿614,462,630 လှူဒါန်းထားပြီး စီမံကိန်း 1,413 ခု ရန်ပုံငွေပြည့်မီကြောင်း ပြထားသည်။ taejai.com
