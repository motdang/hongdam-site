One order workflow at 30,000 runs a month: Zapier US$1,149, Make US$116, a Worker US$5

เวิร์กโฟลว์รับออเดอร์เดียวกัน 30,000 รอบต่อเดือน: Zapier 1,149 ดอลลาร์ Make 116 ดอลลาร์ Worker 5 ดอลลาร์

Zapier bills each action, Make each module, n8n each run. The same five-step order workflow costs US$1,149, US$116.47 or €144 a month at 30,000 runs, and US$5 as code on a Worker. Prices read 24 October 2026.

One order workflow costs US$5 a month on a Cloudflare Worker and US$1,149 on Zapier at 30,000 runs. The workflow is the same; each platform counts a run in a different unit, and the unit sets the bill.

The reference run is one trigger and four actions across three apps

A web form posts each order to a webhook, a web address that hands the order's data to the workflow. The workflow looks the customer up in a Google Sheet, writes the order as a row, emails a confirmation from Gmail and posts a message in Slack. Volumes are 300, 3,000 and 30,000 runs a month, or 10, 100 and 1,000 a day. Prices are list prices read from each vendor's pages on 24 October 2026, for the lowest plan or tier that holds the volume, without the fees of Google, Slack or an email provider. Euro prices are converted to US dollars where compared, at the European Central Bank reference rate of 23 October 2026, EUR 1 = US$1.1193 17.

One run is 4 tasks, 5 credits, 1 execution, 1 request or 1 minute

  • Zapier counts a task for each successful action. The trigger and built-in steps (Filter, Formatter, Paths, Delay) count 0 12. The run is 4 tasks.
  • Make counts a credit for each module action, and reading an incoming webhook is one of them. Router and error-handler modules count 0 34. The run is 5 credits. Make's pricing page dates the switch to credits as its billing unit to 27 August; its help pages still say operations.
  • n8n counts a run of the whole workflow at any number of steps: "An execution is a single run of your entire workflow." 5 The run is 1 execution.
  • Cloudflare Workers is code that Cloudflare runs for each incoming request, so you rent no server. It bills requests, and calls the code makes outward are free. The paid Standard plan also bills CPU time, the processor time the code uses; waiting on the network does not count 67. The run is 1 request.
  • GitHub Actions bills minutes on its runners, with each job rounded up to a whole minute 89. A job that ends in seconds is 1 minute.

Per-step counting grows with the workflow. One more action moves Zapier from 4 to 5 tasks (a quarter more) and Make from 5 to 6 credits (a fifth more). n8n stays at 1 execution, and a Worker adds milliseconds of CPU time, which sit inside the 30 million included at these volumes 6.

The Free plans stop short of the reference run: Zapier's Free plan allows two-step Zaps and 100 tasks, Make's Free plan holds 200 runs in its 1,000 credits, and n8n Cloud opens with a trial capped at 1,000 executions 135. n8n self-hosted: a €5.99 to €26.99 server plus update hours

Self-hosting means running n8n's free Community Edition on a server you rent and update yourself 5. Hetzner lists a 2 vCPU (virtual processor core), 4 GB server at €5.99 a month excluding VAT at its NBG1 and HEL1 locations (CX23), and a 2 vCPU, 4 GB AMD server at €19.99 at those locations and €26.99 at SIN1 in Singapore (CPX22) 1011. The order line on both pages read "currently unavailable" on 24 October 2026. n8n's Hetzner guide asks for at least 4 GB and 2 vCPU once its Assistant feature is added 12. The load is small: n8n's benchmark puts one instance at up to 220 executions a second, and 30,000 runs a month average 0.012 a second 13.

The server price is the smaller part. An update is three commands, docker compose pull, docker compose down and docker compose up -d 14. Read from GitHub on 24 October 2026, n8n published 26 releases, on 17 different days, in the 30 days to that date, and 29 security advisories on two days: 14 on 30 September and 15 on 14 October, 15 medium and 14 high severity 1516. At one hour per update window (time to update and test the workflow), those two days come to 2 hours a month. The hour is an assumption, not a measurement; no source times it.

Step count reverses Make and n8n Cloud

  • A ten-credit run (a trigger and nine actions) at 30,000 runs needs 300,000 Make credits, US$214.31 a month on Core, while n8n Cloud Pro stays at €144 (US$161.18) 35.
  • Up to 200 runs a month, Make's Free plan carries the reference workflow at US$0. At 300 runs the lowest paid tiers are Make US$10.59, n8n Cloud €24 (US$26.86) and Zapier US$58.50.
  • A daily job such as a price check is 30 runs a month. Zapier's lowest Professional tier (750 tasks, US$29.99), Make's lowest Core tier (US$10.59) and n8n Starter (€24) each hold it 135.
  • Code on a Worker or in Actions has no per-step unit; its cost is the time to build and maintain it. The shop price is ฿8,000 a workflow: one trigger, up to three apps, an alert when it stops and 30 days of fixes, in n8n, Make, Zapier or code, with the tool's fees at cost 19.
