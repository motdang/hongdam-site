  1. 01

    ปิดงานโค้ด

    แอปที่สร้างด้วย Lovable, Bolt, Replit หรือ Cursor: อ่าน แก้ ทดสอบ และเผยแพร่บนบัญชีของคุณเอง

    • ทำโค้ดที่เขียนด้วย AI ให้เสร็จLovable Bolt Replit Cursor อ่าน แก้ เผยแพร่เริ่ม ฿5,000ซื้อ
    • ย้ายโฮสติ้งย้ายเว็บ โดเมน อีเมล จาก Wix WordPress หรืออื่น ๆ฿5,000ซื้อ
    • ดูแลเว็บไซต์อัปเดต สำรองข้อมูล บอกเมื่อเว็บล่ม แก้ 2 ชั่วโมงต่อเดือน฿3,000 / เดือนซื้อ
    • ตั้งค่า Google และ AIตั้งค่า Search Console แผนผังเว็บ ชื่อหน้า llms.txt฿5,000ซื้อ
    • อีก 4 รายการ
      • อ่านง่ายขึ้นตรวจความต่างสี ตัวใหญ่ อ่านออกเสียง โปรแกรมอ่านหน้าจอ พร้อมรายการแก้฿15,000ซื้อ
      • สำเนาสำรองของเว็บบนโฮสต์ที่สอง สลับใช้เมื่อเว็บล่ม฿5,000ซื้อ
      • ช่องค้นหาสำหรับเว็บไทยและอังกฤษ ค้นในเว็บของคุณ฿5,000ซื้อ
      • ให้ AI อ่าน WordPress ของคุณปลั๊กอิน API อ่านอย่างเดียว฿10,000ซื้อ

    ทั้งหมดในหมวด เว็บและแอป

  2. 02

    ความปลอดภัย

    ทดสอบโจมตีแชตบอตแล้วแก้ แพตช์ PHP และ WordPress ล้างเว็บที่ถูกแฮ็ก ตั้งค่าระเบียนอีเมลของโดเมนคุณ และตรวจอุปกรณ์เพื่อเก็บหลักฐาน

    • แก้ PHP หรือ WordPressแพตช์ช่องโหว่ PHP2Shell บนเว็บหรือเซิร์ฟเวอร์เริ่ม ฿3,000จอง
    • ทดสอบเจาะแชตบอทเราลองเจาะแล้วเขียนวิธีแก้฿12,000ซื้อ
    • ทดสอบแชตบอทด้วยตัวเองวางคำสั่ง เลือกชุดทดสอบ อ่านผลฟรีเปิด
    • กู้เว็บที่ถูกแฮกลบมัลแวร์ ปิดทางเข้า พร้อมรายงาน฿5,000 / เว็บซื้อ
    • อีก 3 รายการ
      • กันอีเมลปลอมในชื่อคุณอ่าน SPF DKIM DMARC ของโดเมน พร้อมวิธีแก้เริ่ม ฿1,500ซื้อ
      • ทดสอบแอปบนมือถือคนไทยคนไทยใช้งานแล้วรายงานจุดที่เสีย฿5,000ซื้อ
      • ตรวจพิสูจน์อุปกรณ์ทำสำเนาและอ่านคอมพิวเตอร์หรือโทรศัพท์ บันทึกการครอบครองเป็นกรณีไปเขียนถึงเรา

    ทั้งหมดในหมวด แก้ไขและป้องกัน

  3. 03

    โมเดล AI

    เลือกโมเดลภาษาด้วยการวัดผล: ผู้ช่วย AI ที่ตอบจากหน้าเว็บของคุณ เครื่องสร้างเว็บด้วย AI บนคอมพิวเตอร์ของคุณเอง ไฟล์ใหญ่ที่ AI จัดให้เรียบร้อย และราคาที่ขยับตามความต้องการ

    • ผู้ช่วย AI ในชื่อของคุณตอบจากหน้าเว็บของคุณ มีที่นั่งให้ทีมเริ่ม ฿20,000ซื้อ
    • เครื่องสร้างเว็บด้วย AI ของคุณเองบนคอมพิวเตอร์และบัญชีของคุณ ติดตั้งและสอนเริ่ม ฿25,000ซื้อ
    • ไลน์เดียวหลายร้านไลน์ OA เดียวตอบแทนหลายธุรกิจ฿20,000ซื้อ
    • ทำความสะอาดหรือจัดไฟล์ใหญ่ด้วย AIหลายพันแถว ทำความสะอาด จัดเรียง หรือสรุป฿1,000ซื้อ
    • อีก 3 รายการ
      • ราคาที่ขยับตามความต้องการห้อง เมนู บัตร ขายดีขึ้นหนึ่งขั้น เงียบลงหนึ่งขั้น฿20,000ซื้อ
      • เก็บเงินบอท AIดูว่าบอทไหนอ่านเว็บ ตั้งค่า pay-per-crawl฿5,000ซื้อ
      • บอทนำเสนอเดโมบน Zoomภาษาไทยหรืออังกฤษ สำหรับบริษัทซอฟต์แวร์ราคาตามงานเขียนถึงเรา

    ทั้งหมดในหมวด AI และบอท

    ระบบอัตโนมัติ

    งานที่เดินเอง: เวิร์กโฟลว์ใน n8n, Make, Zapier หรือโค้ด บอตที่หางานหรือข่าว และตัวเก็บข้อมูลที่อ่านเว็บลงตาราง

    • ระบบอัตโนมัติงานที่ทำเองอัตโนมัติด้วย n8n Make Zapier หรือโค้ด฿8,000 / ระบบซื้อ
    • บอทหางานหรือข่าวสเกาต์ โต๊ะค่าหัว และบอทหาเงิน ซื้อหรือให้เราดูแลเริ่ม ฿3,000จอง
    • โปรแกรมเก็บข้อมูลอ่านเว็บหรือไฟล์ตามรอบ ลงตาราง฿6,000ซื้อ
    • ติดตามราคาราคาคู่แข่งและสต็อก ทุกวัน ลงตาราง฿1,500 / เดือนซื้อ
    • อีก 2 รายการ
      • นับผู้เข้าชม คนและบอทยอดเข้าชมรายสัปดาห์ แยกคนกับบอท฿1,200 / เดือนซื้อ
      • ค้นคว้าคำถามให้ตอบเป็นลายลักษณ์อักษร มีแหล่งที่มา฿1,200 / คำถามซื้อ

    ฐานข้อมูล Supabase 16,326 แห่งเปิดให้ใครก็อ่านตารางได้ ตรวจแอปของคุณเองใน 2 นาที

    16,326 Supabase databases answer to the public key: check yours in two minutes

    UpGuard พบฐานข้อมูล Supabase 16,326 แห่งที่ใครมีคีย์สาธารณะก็อ่านตารางได้ บันทึกนี้มีวิธีตรวจโปรเจกต์ของคุณเองใน 2 นาที SQL ที่ปิดช่องโหว่ และสิ่งที่ Supabase เปลี่ยนในวันที่ 30 ตุลาคม

  • ความปลอดภัย · 24 ต.ค. 2569

    PHP2Shell: PHP 8.5.12, 8.4.27, 8.3.36 และ 8.2.35 ปิดช่องโหว่สั่งรันโค้ดจากระยะไกล 2 รายการ

    PHP2Shell: PHP 8.5.12, 8.4.27, 8.3.36 and 8.2.35 close two remote-code flaws

    ช่องโหว่ PHP 2 รายการ (CVE-2026-109618 และ CVE-2026-109619) ให้คนแปลกหน้าสั่งรันโค้ดบนเว็บเซิร์ฟเวอร์ได้โดยไม่ต้องล็อกอิน แพตช์ออก 21 ตุลาคม 2569 แต่การโจมตีเริ่มตั้งแต่ 17 ตุลาคม และหลังอัปเดตต้องรีสตาร์ตโปรเซส PHP ด้วย

  • ระบบอัตโนมัติ · 24 ต.ค. 2569

    เวิร์กโฟลว์รับออเดอร์เดียวกัน 30,000 รอบต่อเดือน: Zapier 1,149 ดอลลาร์ Make 116 ดอลลาร์ Worker 5 ดอลลาร์

    One order workflow at 30,000 runs a month: Zapier US$1,149, Make US$116, a Worker US$5

    Zapier คิดเงินต่อ action, Make คิดต่อโมดูล, n8n คิดต่อรอบ เวิร์กโฟลว์รับออเดอร์ 5 ขั้นตอนเดียวกันจึงมีค่าใช้จ่ายที่ 30,000 รอบต่อเดือนตั้งแต่ 5 ดอลลาร์ (โค้ดบน Cloudflare Worker) ถึง 1,149 ดอลลาร์ (Zapier) อ่านราคาจากหน้าของผู้ให้บริการเมื่อ 24 ตุลาคม 2569
