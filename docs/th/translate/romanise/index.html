  • ในเอกสารที่ไทยเสนอต่อการประชุมสหประชาชาติว่าด้วยการกำหนดมาตรฐานชื่อภูมิศาสตร์ ระบบถอดอักษรของราชบัณฑิตยสถานเขียนตามเสียงของคำไทยโดยไม่คำนึงถึงตัวสะกดเดิม และไม่แสดงวรรณยุกต์ เครื่องหมายทัณฑฆาต หรือความยาวของสระ unstats.un.org

  • ชื่อเฉพาะที่เป็นคำยืมให้เขียนตามต้นฉบับ เช่น First Class Co.Ltd. ส่วนคำยืมที่เป็นเพียงส่วนหนึ่งของชื่อให้ถอดตามเสียงอ่านภาษาไทย unstats.un.org
  • ตัวอย่างในเอกสารมี Nai Somchai Khonching สำหรับชื่อบุคคล Wat Duang Khae สำหรับวัด และ Rongrian Sattri Witthaya สำหรับโรงเรียน unstats.un.org

คำถามที่คนถาม

ชื่อภาษาไทยเขียนเป็นอักษรอังกฤษอย่างไร

ในเอกสารที่ไทยเสนอต่อการประชุมสหประชาชาติ ระบบถอดอักษรของราชบัณฑิตยสถานเขียนตามเสียงอ่านของคำ ไม่ว่าสะกดเป็นไทยอย่างไร ตัวอย่างชื่อบุคคลคือ Nai Somchai Khonching unstats.un.org

การสะกดภาษาอังกฤษแสดงวรรณยุกต์ไหม

ไม่แสดงในระบบถอดอักษรของราชบัณฑิตยสถาน เอกสารระบุว่าวรรณยุกต์ เครื่องหมายกำกับ รวมทั้งทัณฑฆาต และความยาวของสระ ไม่นำมาแสดง เขียนเฉพาะเสียง unstats.un.org

ชื่อสถานที่ในไทยเขียนอย่างไร

เอกสารระบุว่าชื่อทางภูมิศาสตร์ไม่แปล และใช้กฎการถอดอักษรทั่วไปกับทั้งชื่อ เช่น Ko Si Chang และ Thanon Tha Phra unstats.un.org

ชื่อบริษัทที่มีคำอังกฤษถูกเปลี่ยนไหม

เอกสารระบุว่าคำยืมที่เป็นชื่อเฉพาะให้เขียนตามต้นฉบับ เช่น First Class Co.Ltd. ส่วนคำยืมที่เป็นเพียงส่วนหนึ่งของชื่อให้เขียนตามเสียงอ่านภาษาไทย unstats.un.org
