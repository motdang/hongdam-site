ข้อมูลน่ารู้

  • W3C ระบุให้ใส่แอตทริบิวต์ภาษาที่แท็ก html เพื่อประกาศภาษาหลักของข้อความในหน้า องค์ประกอบอื่นสืบทอดค่านี้ และเนื้อหาที่ผสมหลายภาษาให้ใส่แอตทริบิวต์ที่องค์ประกอบที่ครอบเนื้อหานั้น w3.org
  • Google ระบุว่าไม่ใช้ hreflang หรือแอตทริบิวต์ lang ของ HTML เพื่อตรวจจับภาษาของหน้า แต่ใช้อัลกอริทึมของตนเอง developers.google.com

  • ผู้พิสูจน์อักษรภาษาไทยบน Fastwork รายหนึ่งตรวจเฉพาะคำสะกดผิด การเว้นวรรค และเครื่องหมาย และรับเฉพาะต้นฉบับภาษาไทย fastwork.co

คำถามที่คนถาม

พิสูจน์อักษรในไทยราคาเท่าไร

ผู้ขายบน Fastwork รายหนึ่งพิสูจน์อักษรภาษาไทยหน้า A4 ฟอนต์ 16 ละ ฿10 และหน้า A5 ละ ฿5 โดยตรวจคำสะกดผิด การเว้นวรรค และเครื่องหมาย fastwork.co

ทำอย่างไรให้หน้าเว็บระบุว่าเป็นภาษาไทยหรืออังกฤษ

W3C ระบุให้ใส่แอตทริบิวต์ภาษาที่แท็ก html เช่น <html lang="en"> สำหรับภาษาอังกฤษ องค์ประกอบอื่นสืบทอดค่านี้ และเนื้อหาในอีกภาษาหนึ่งให้ใส่แอตทริบิวต์ของตนเอง รหัสย่อยภาษามาจาก IANA Language Subtag Registry w3.org

Google อ่านแอตทริบิวต์ lang ของหน้าเว็บไหม

Google ระบุว่าไม่ใช้ hreflang หรือแอตทริบิวต์ lang ของ HTML เพื่อตรวจจับภาษาของหน้า แต่ใช้อัลกอริทึม ส่วน hreflang ใช้จับคู่หน้ากับเวอร์ชันภาษาอื่นของหน้านั้น developers.google.com

การพิสูจน์อักษรเขียนข้อความของฉันใหม่ไหม

ผู้ตรวจภาษาอังกฤษบน Fastwork รายหนึ่งระบุว่าให้ความเห็นและข้อเสนอแนะ และไม่รับเรียบเรียงใหม่หรือเขียนใหม่ fastwork.co
