แปลภาษาไทใหญ่

คนแปลประกาศ แบบฟอร์ม และจดหมายเป็นภาษาไทใหญ่ให้ผู้อ่านที่ใช้ภาษานี้ ซึ่งมีผู้พูดโดยประมาณ 3.2 ล้านคนในรัฐฉาน

ราคาวันนี้ ฿800 / หน้า

ซื้อ ถามทางไลน์

สิ่งที่ได้

  • แปลภาษาไทใหญ่฿800 / หน้าแปลเป็นภาษาไทใหญ่จากไทย อังกฤษ หรือพม่า

ซื้อ ถามทางไลน์

ขั้นตอน

  1. คุณส่งข้อความ เป็นภาษาไทย อังกฤษ หรือพม่าคุณ · ตอนสั่งซื้อ
  2. เราแปลข้อความเป็นภาษาไทใหญ่หงส์ดำ · หลังได้รับข้อความ
  3. ส่งข้อความภาษาไทใหญ่กลับให้คุณหงส์ดำ · ขั้นสุดท้าย

ข้อมูลน่ารู้

  • เอกสารการถอดอักษรโรมันของ BGN/PCGN ระบุว่าภาษาไทใหญ่เป็นภาษาตระกูลไท พูดในพม่า มีผู้พูดโดยประมาณ 3.2 ล้านคนในรัฐฉาน และระบบการเขียนพัฒนามาจากอักษรพม่า assets.publishing.service.gov.uk
  • ตารางอักษรไทใหญ่สมัยใหม่ในเอกสารนี้มีพยัญชนะ 20 ตัว และเอกสารระบุว่ามี 5 วรรณยุกต์ซึ่งการถอดอักษรโรมันไม่ได้แสดง assets.publishing.service.gov.uk
  • ยูนิโคดจัดอักษร สระ และเครื่องหมายวรรณยุกต์ของภาษาไทใหญ่ไว้ในบล็อก Myanmar (U+1000–109F) ร่วมกับอักษรพม่า มอญ และกะเหรี่ยง unicode.org

คำถามที่คนถาม

ภาษาไทใหญ่อยู่ในตระกูลภาษาอะไร

เอกสาร BGN/PCGN ระบุว่าเป็นภาษาตระกูลไทที่พูดในพม่า และระบุว่าระบบการเขียนพัฒนามาจากอักษรพม่า assets.publishing.service.gov.uk

มีคนพูดภาษาไทใหญ่กี่คน

เอกสาร BGN/PCGN ให้ตัวเลขผู้พูดโดยประมาณ 3.2 ล้านคนในรัฐฉาน โดยอ้างจาก Ethnologue ฉบับที่ 16 (2009) assets.publishing.service.gov.uk

พิมพ์ภาษาไทใหญ่บนคอมพิวเตอร์ได้ไหม

ได้ ใน Unicode บล็อก Myanmar (U+1000–109F) มีอักษร สระ และเครื่องหมายวรรณยุกต์ของภาษาไทใหญ่ ร่วมกับอักษรพม่า มอญ และกะเหรี่ยง unicode.org

แปลภาษาไทใหญ่ราคาเท่าไร

ผู้ขายบน Fastwork รายหนึ่งตั้งราคาไทย–ไทใหญ่ และพม่า–ไทย หน้าละ ฿250–300 และอังกฤษ–ไทย หน้าละ ฿200–250 แพ็กเกจ ฿250 ถึง ฿350 ใช้เวลา 1 ถึง 2 วัน แก้ไขได้ 2 ครั้ง fastwork.co
