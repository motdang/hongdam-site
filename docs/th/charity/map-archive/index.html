ข้อมูลน่ารู้

  • แผนที่ใน Google My Maps เริ่มด้วยหนึ่งเลเยอร์ และมีได้สูงสุด 10 เลเยอร์ เลเยอร์ใช้จัดกลุ่มรายการบนแผนที่ เช่น เลเยอร์หนึ่งสำหรับร้านอาหาร อีกเลเยอร์สำหรับร้านกาแฟ support.google.com
  • การฝังแผนที่ Google My Maps ลงในเว็บไซต์ต้องตั้งแผนที่เป็นสาธารณะ หน้าช่วยเหลือระบุตัวเลือกการแชร์สองแบบ คือแชร์ผ่านลิงก์ ซึ่งให้ URL กับคนที่เลือก และสาธารณะ ซึ่งให้ทุกคนค้นเจอแผนที่ได้ support.google.com
  • uMap เป็นซอฟต์แวร์เปิดเผยซอร์สโค้ดที่ใช้ฟรี สำหรับทำแผนที่บนเลเยอร์ของ OpenStreetMap และนำแผนที่ไปใส่ในเว็บไซต์ของคุณได้ ชุมชนผู้ร่วมพัฒนาดูแลโครงการ และกลุ่ม OpenStreetMap ในเยอรมนี สวิตเซอร์แลนด์ และฝรั่งเศสให้บริการสำเนา umap-project.org
  • นโยบายแผนที่ย่อยของ OpenStreetMap อนุญาตให้ใช้ภาพแผนที่บนเว็บไซต์เมื่อแสดงเครดิต OpenStreetMap ให้เห็นชัดบนแผนที่ จำกัดการใช้งานหนัก อาจบล็อกการเข้าถึงโดยไม่แจ้งล่วงหน้า และให้บริการตามกำลังที่ทำได้ operations.osmfoundation.org
  • Google ระบุว่าการใช้ Maps Embed API ไม่มีค่าใช้จ่าย ต้องใช้คีย์ API และไม่มีขีดจำกัดต่อวินาทีหรือต่อวัน developers.google.com

คำถามที่คนถาม

มีเครื่องมือฟรีสำหรับทำแผนที่สถานที่ไหม

uMap เป็นซอฟต์แวร์เปิดเผยซอร์สโค้ดที่ใช้ฟรี สร้างแผนที่บนเลเยอร์ของ OpenStreetMap และนำแผนที่ไปใส่ในเว็บไซต์ของคุณได้ umap-project.org

ใส่แผนที่ Google ในเว็บไซต์ของฉันได้ฟรีไหม

Google ระบุว่าการใช้ Maps Embed API ไม่มีค่าใช้จ่าย ต้องใช้คีย์ API และไม่มีขีดจำกัดต่อวินาทีหรือต่อวัน developers.google.com

แผนที่ Google My Maps มีเลเยอร์ได้กี่ชั้น

แผนที่เริ่มด้วยหนึ่งเลเยอร์ และมีได้สูงสุด 10 เลเยอร์ หน้าช่วยเหลือของ Google ยกตัวอย่างเลเยอร์หนึ่งสำหรับร้านอาหาร และอีกเลเยอร์สำหรับร้านกาแฟ support.google.com

ส่งออกข้อมูลสถานที่จาก Google My Maps ได้ไหม

ได้ หน้าช่วยเหลือระบุว่าส่งออกแผนที่เป็นไฟล์ KML หรือ KMZ ได้ ส่วนเลเยอร์แต่ละชั้นส่งออกเป็น CSV ได้ แต่แผนที่ทั้งแผนที่ส่งออกเป็น CSV ไม่ได้ support.google.com

Felt ราคาเท่าไร และมีส่วนลดสำหรับองค์กรไม่แสวงกำไรไหม

แผนฟรีของ Felt ให้สร้างและใส่คำอธิบายบนแผนที่ แชร์แบบสาธารณะ และมีผู้ดูแผนที่ได้ 10k ครั้งต่อเดือน แผน Team ราคา US$199 และ Business US$599 ต่อเดือน เมื่อจ่ายรายปี องค์กรไม่แสวงกำไร 501(c)(3) ของสหรัฐฯ ลด 30% สำหรับแผนที่ต้องจ่ายเงิน felt.com
