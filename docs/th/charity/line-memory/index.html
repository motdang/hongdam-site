คำถามที่คนถาม

สมาชิกใหม่ของกลุ่มไลน์เห็นข้อความเก่าไหม

ไม่เห็นข้อความแชทที่ส่งก่อนเข้ากลุ่ม หน้าช่วยเหลือของ LINE ระบุว่า สมาชิกใหม่เห็นโพสต์ใน Note และ Album ที่ลงไว้ระหว่างที่คำเชิญยังรออยู่ แต่ไม่เห็นข้อความแชทก่อนหน้านั้น help.line.me

กลุ่มไลน์มีสมาชิกได้กี่คน

สูงสุด 500 คน รวมผู้สร้างกลุ่ม ถ้าเปิด "สมาชิกเข้าร่วมอัตโนมัติ" สูงสุด 100 คน help.line.me

ประวัติของกลุ่มเป็นอย่างไร เมื่อมีคนออกหรือลบกลุ่ม

คนที่ออกจากกลุ่มดูโพสต์ อัลบั้ม และโน้ตเก่าไม่ได้อีก หน้าช่วยเหลือของ LINE ระบุว่าสิ่งเหล่านี้ยังอยู่สำหรับสมาชิกที่เหลือ กลุ่มที่ถูกลบจะสูญเสียทุกอย่างที่โพสต์ไว้และกู้คืนไม่ได้ help.line.me

LINE Official Account ในไทยราคาเท่าไร

หน้าไทยของ LINE ระบุ 3 แพ็กเกจ ฟรี 300 ข้อความ เบสิก ฿1,280 ต่อเดือน 15,000 ข้อความ และโปร ฿1,780 ต่อเดือน 35,000 ข้อความ ข้อความที่เกินแพ็กเกจคิด ฿0.1 บนเบสิก และ ฿0.06 บนโปร ราคายังไม่รวม VAT 7% lineforbusiness.com

แชทบอท LINE บน Fastwork ราคาเท่าไร

ประกาศหนึ่งบน Fastwork สำหรับแชทบอท LINE OA แบบ AI ตั้งราคา ฿15,000 สำหรับ Starter ที่ตอบคำถามและส่งต่อให้แอดมิน ฿20,000 สำหรับ Advanced ที่เพิ่มรับออเดอร์และจองคิว และ ฿30,000 สำหรับ Operation ที่เพิ่มเชื่อม Google Sheet รายงาน และดูแล 14 วัน fastwork.co
