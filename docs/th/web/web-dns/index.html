ย้ายการตั้งค่าโดเมนไป Cloudflare

หลายคนย้าย DNS ของโดเมนไปบัญชี Cloudflare ฟรี ให้เว็บเปิดได้ทั้งมีและไม่มี www และยกเลิกโฮสต์เก่าได้

ราคาวันนี้ ฿2,000

ซื้อ ถามทางไลน์

สิ่งที่ได้

  • ย้ายการตั้งค่าโดเมน ตรวจระเบียนอีเมล฿2,000ย้าย DNS ของโดเมน (การตั้งค่าที่บอกว่าเว็บและอีเมลอยู่ที่ไหน) ไปบัญชี Cloudflare ฟรีในชื่อของคุณ ก่อนสลับ เราตรวจระเบียนอีเมลทุกตัวว่าตรงกันทั้งที่เก่าและที่ใหม่ หลังจากนั้นเว็บเปิดได้ทั้งมีและไม่มี www และยกเลิกโฮสต์เก่าที่ไม่ได้ใช้แล้วได้

ซื้อ ถามทางไลน์

ขั้นตอน

  1. คุณเข้าสู่ระบบผู้รับจดโดเมน (บริษัทที่คุณจ่ายค่าโดเมน) พร้อมเราทางวิดีโอคอลคุณและหงส์ดำ · ขั้นแรก
  2. บัญชี Cloudflare ฟรีในชื่อคุณคัดลอกการตั้งค่า และเราตรวจระเบียนอีเมลทุกตัวหงส์ดำ · จากนั้น
  3. เปลี่ยนเนมเซิร์ฟเวอร์ที่ผู้รับจดโดเมน Cloudflare บอกว่าอาจใช้เวลาถึง 24 ชั่วโมงหงส์ดำ · จากนั้น
  4. ตรวจเว็บทั้งมีและไม่มี www และระเบียนอีเมลอีกครั้งหงส์ดำ · ขั้นสุดท้าย

ข้อมูลน่ารู้

  • Cloudflare สแกนหาระเบียน DNS เดิมของโดเมนแล้วเพิ่มให้ได้ แต่หน้าของ Cloudflare บอกว่าการสแกนอาจหาไม่ครบ ต้องตรวจระเบียนของโดเมนเอง www และอีเมล developers.cloudflare.com
  • หน้าของ Cloudflare บอกให้รอได้ถึง 24 ชั่วโมงระหว่างที่ผู้รับจดโดเมนอัปเดตเนมเซิร์ฟเวอร์ developers.cloudflare.com
  • Cloudflare บอกให้ปิด DNSSEC ที่ผู้รับจดโดเมนก่อนเปลี่ยนเนมเซิร์ฟเวอร์ เพราะถ้าเปลี่ยนตอนเปิดอยู่ โดเมนอาจเข้าไม่ได้ developers.cloudflare.com
  • ทุกแพ็กเกจของ Cloudflare ระเบียน CNAME บนโดเมนเอง (yourshop.com ไม่มี www) ถูก flatten โดยค่าเริ่มต้น จึงใช้ได้ ในขณะที่ผู้ให้บริการ DNS อื่นหลายรายไม่รับ developers.cloudflare.com
  • Cloudflare Email Routing ในแพ็กเกจฟรี ส่งอีเมลขาเข้าของที่อยู่บนโดเมนไปยังกล่องที่คุณใช้อยู่ ใช้ได้กับอีเมลขาเข้าเท่านั้น developers.cloudflare.com

คำถามที่คนถาม

อีเมลของฉันจะใช้ไม่ได้ไหม

Cloudflare บอกว่าการสแกนอาจตกหล่น และค่าของอีเมลขึ้นกับผู้ให้บริการอีเมลของคุณ เราตรวจระเบียนอีเมลทุกตัวทั้งที่เก่าและที่ใหม่ก่อนสลับ และตรวจอีกครั้งหลังสลับ developers.cloudflare.com

สลับใช้เวลานานแค่ไหน

หน้าของ Cloudflare บอกว่าถึง 24 ชั่วโมงระหว่างที่ผู้รับจดโดเมนอัปเดตเนมเซิร์ฟเวอร์ developers.cloudflare.com

ตัวโดเมนย้ายด้วยไหม

ไม่ โดเมนยังอยู่กับผู้รับจดโดเมนเดิม เปลี่ยนแค่เนมเซิร์ฟเวอร์ ถ้าต้องการ Cloudflare Registrar รับโดเมนได้ในราคาของ registry developers.cloudflare.com

Cloudflare เก็บเงินไหม

แพ็กเกจฟรีไม่เสียเงิน และมีใบรับรอง SSL ฟรี cloudflare.com
