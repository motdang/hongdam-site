ข้อมูลน่ารู้

  • ภาษาไทย จีน ญี่ปุ่น ลาว เขมร และพม่าไม่เว้นวรรคระหว่างคำ การตัดคำด้วยช่องว่างจึงได้คำที่ผิด เบราว์เซอร์มี Intl.Segmenter สำหรับตัดคำ และใช้ได้ข้ามเบราว์เซอร์ตั้งแต่เมษายน 2024 developer.mozilla.org
  • Custom Search JSON API ของ Google ปิดรับลูกค้าใหม่แล้ว ลูกค้าเดิมมีเวลาถึง 1 มกราคม 2027 เพื่อย้ายไปใช้ทางเลือกอื่น Google เสนอ Vertex AI Search เป็นทางเลือกสำหรับการค้นหาได้ถึง 50 โดเมน developers.google.com
  • Pagefind เป็นไลบรารีค้นหาแบบสถิตโอเพนซอร์สที่ไม่ขึ้นกับผู้ใด ทำงานกับ HTML แบบสถิตได้ทุกแบบ และเพิ่มชุดค้นหาแบบสถิตเข้าไปในไฟล์ที่สร้างแล้ว หน้าเว็บระบุว่ารองรับเว็บหลายภาษาโดยไม่ต้องตั้งค่า และทำงานได้โดยไม่ต้องโฮสต์โครงสร้างพื้นฐานเอง pagefind.app

คำถามที่คนถาม

จะเพิ่มช่องค้นหาในเว็บไซต์ได้อย่างไร

ไลบรารีสำหรับเว็บสถิตอย่าง Pagefind เพิ่มชุดค้นหาเข้าไปในไฟล์ที่สร้างแล้ว และการค้นหาทำงานในเบราว์เซอร์ของผู้เข้าชม โดยไม่ต้องมีบริการค้นหาที่โฮสต์ไว้ pagefind.app

ใช้ Google ค้นหาในเว็บของตัวเองได้ไหม

Custom Search JSON API ของ Google ปิดรับลูกค้าใหม่ ลูกค้าเดิมมีเวลาถึง 1 มกราคม 2027 เพื่อย้าย และ Google เสนอ Vertex AI Search สำหรับค้นหาได้ถึง 50 โดเมน developers.google.com

ค้นหาในเว็บภาษาไทยได้ไหม

ภาษาไทยไม่เว้นวรรคระหว่างคำ การตัดคำด้วยช่องว่างจึงได้คำผิด เบราว์เซอร์มี Intl.Segmenter สำหรับตัดคำภาษาไทยและภาษาอื่นแบบนี้ และใช้ได้ข้ามเบราว์เซอร์ตั้งแต่เมษายน 2024 developer.mozilla.org
