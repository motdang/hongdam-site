ข้อมูลน่ารู้

  • WordPress มี REST API ที่มี endpoint สำหรับโพสต์ หน้า หมวดหมู่ และข้อมูลพื้นฐานอื่น ๆ แอปส่งและรับ JSON ที่ endpoint เหล่านั้นเพื่อค้นหา แก้ไข และสร้างเนื้อหา developer.wordpress.org
  • คำขอไปที่ /wp-json/wp/v2/posts ได้รายการโพสต์ ค่าเริ่มต้นคือ 10 โพสต์ต่อหน้า สถานะ publish และบริบท view developer.wordpress.org
  • WordPress 6.9 เพิ่ม Abilities API เป็นทะเบียนที่ปลั๊กอิน ธีม และแกนหลักใช้อธิบายสิ่งที่ทำได้ในรูปแบบที่เครื่องอ่านได้ โพสต์เมื่อ 10 พฤศจิกายน 2025 เรียกว่าเป็นพื้นฐานสำหรับเอเจนต์ AI และเครื่องมืออัตโนมัติ make.wordpress.org
  • endpoint REST ของ Abilities API อยู่ใต้ wp-abilities/v1 และมีเฉพาะ ability ที่ลงทะเบียนโดยตั้ง show_in_rest เป็น true โพสต์ระบุว่าต้องมีผู้ใช้ที่ยืนยันตัวตนแล้ว make.wordpress.org

คำถามที่คนถาม

WordPress มี API อยู่แล้วหรือไม่

มี WordPress มี REST API มาให้ มี endpoint สำหรับโพสต์ หน้า หมวดหมู่ และข้อมูลพื้นฐานอื่น ๆ และส่งคืนเป็น JSON developer.wordpress.org

WordPress Abilities API คืออะไร

เป็นระบบใน WordPress 6.9 ที่ปลั๊กอิน ธีม และแกนหลักลงทะเบียนสิ่งที่ทำได้ในรูปแบบมาตรฐานที่เครื่องอ่านได้ ability หนึ่งมีป้ายชื่อ คำอธิบาย หมวด สคีมาอินพุตและเอาต์พุต ฟังก์ชันที่รัน และฟังก์ชันตรวจสิทธิ์ make.wordpress.org

แอปอื่นล็อกอินเข้า WordPress REST API อย่างไร

การยืนยันตัวตนด้วยคุกกี้เป็นวิธีมาตรฐานของ WordPress สำหรับผู้ใช้ที่ล็อกอินอยู่ใน WordPress สำหรับแอปอื่น รหัสผ่านแอปพลิเคชันส่งข้อมูลรับรองผ่าน HTTPS ด้วย Basic Auth developer.wordpress.org

ปลั๊กอิน WordPress แบบเขียนเองราคาเท่าไร

Codeable ระบุพัฒนาปลั๊กอินตามสั่งเริ่ม US$960 ผู้เชี่ยวชาญคิดชั่วโมงละ US$80–120 และบวกค่าบริการ 17.5% จากราคาประเมิน codeable.io
