ข้อมูลน่ารู้

  • LY Corporation บริษัทเจ้าของ LINE ระบุผู้ใช้ LINE รายเดือนในประเทศไทย 54 ล้านคน ณ วันที่ 31 มีนาคม 2569 คิดเป็น 81.8% ของประชากร โดยใช้ตัวเลขประชากรปี 2567 ราว 65.95 ล้านคนจากกระทรวงมหาดไทย lycorp.co.jp
  • LINE MINI App คือเว็บแอปพลิเคชันที่ทำงานบน LINE เปิดได้จากในแอป LINE ลิงก์ถาวร LINE Official Account แท็บหน้าหลัก การค้นหา หรือข้อความที่แชร์ developers.line.biz
  • แชนเนล LINE MINI App ที่สร้างใหม่เป็น MINI App ที่ยังไม่ผ่านการตรวจสอบ และบางฟีเจอร์ถูกจำกัด สำหรับบริการในประเทศไทย เฉพาะแชนเนลที่อยู่ภายใต้ผู้ให้บริการที่ได้รับการรับรอง (certified provider) เท่านั้นที่ยื่นขอตรวจสอบได้ developers.line.biz
  • LINE นับข้อความเป็นจำนวนคำขอคูณจำนวนผู้รับ ข้อความตอบกลับไม่นับรวมในจำนวนข้อความของแพ็กเกจ และข้อความที่ส่งถึงผู้ใช้ที่บล็อกบัญชีก็ไม่นับ developers.line.biz
  • เอกสาร Messaging API ระบุว่าเมื่อส่งเกินจำนวนข้อความต่อเดือน ระบบจะตอบกลับเป็นข้อผิดพลาดและข้อความจะไม่ถูกส่ง developers.line.biz
  • บัญชี LINE Official Account ที่ผ่านการพิจารณาของ LINE จะได้รับตรารับรอง (Verified account badge) ขณะนี้ LINE รับสมัครในญี่ปุ่น ไต้หวัน และไทย และไม่ออกบัญชีรับรองให้ประเทศหรือภูมิภาคอื่น help.line.me

คำถามที่คนถาม

LINE Official Account คืออะไร

LINE ประเทศไทยอธิบายว่าเป็นบัญชีทางการของธุรกิจบน LINE ร้านค้าใช้สร้างฐานผู้ติดตามและส่งข้อมูลการขายหรือโปรโมชั่นถึงลูกค้า ฟีเจอร์มีข้อความทักทาย ข้อความตอบกลับอัตโนมัติ คูปองและบัตรสะสมแต้ม การแชท 1-1 และการบรอดแคสต์ lineforbusiness.com

ทำ LINE OA เสียเงินไหม

เมื่อเปิดบัญชีทางการจะส่งข้อความฟรีได้ 300 ข้อความต่อเดือน LINE ประเทศไทยมีแพ็กเกจรายเดือนให้เลือกเพิ่มอีกสองแบบ คือ เบสิก ฿1,280 ได้ 15,000 ข้อความ และโปร ฿1,780 ได้ 35,000 ข้อความ ราคายังไม่รวม VAT 7% lineforbusiness.com

ล็อกอิน LINE OA ทำอย่างไร

บนคอมพิวเตอร์ LINE Official Account Manager อยู่ที่ manager.line.biz บนมือถือใช้แอปพลิเคชัน Official Account ทั้งสองทางล็อกอินด้วยบัญชีไลน์หรือบัญชีธุรกิจ lineforbusiness.com

LINE MINI App ต่างจาก LIFF อย่างไร

LY Corporation ระบุว่าในที่สุด LIFF จะรวมเข้ากับแบรนด์ LINE MINI App และสนับสนุนให้สร้างแอป LIFF ใหม่เป็น LINE MINI App ฟีเจอร์ LIFF บางอย่างไม่มีใน MINI App: ซ่อนปุ่มแอ็กชันไม่ได้ ตั้งค่า Module Mode ไม่ได้ หนึ่งแชนเนลมีเว็บแอปได้หนึ่งตัว และขนาดหน้าจอถูกกำหนดเป็น Full developers.line.biz

ใครสร้าง LINE MINI App ได้

นักพัฒนา LINE Developers ระบุว่าการสร้างแชนเนล LINE MINI App ต้องมีบัญชี LINE Developers Console ตัวแอปเป็นเว็บแอปพลิเคชันที่ทำงานบน LINE developers.line.biz

LINE OA ทำร้านค้าได้ไหม

LINE ประเทศไทยระบุ MyShop ไว้ข้างแพ็กเกจ เป็นเครื่องมือสร้างหน้าร้านและช่วยปิดการขายให้ LINE OA ออเดอร์ที่สำเร็จผ่าน MyShop มีค่าธรรมเนียมตามเงื่อนไขที่ LINE กำหนด lineforbusiness.com

ลูกค้าจองและจ่ายมัดจำในไลน์ได้ไหม

ผู้ขายบน Fastwork มีบริการระบบจองผ่าน LINE OA ในประกาศหนึ่ง แพ็กเกจเริ่มต้นรับจองและส่งข้อมูลการจองไปยัง LINE OA แพ็กเกจถัดไปเพิ่มการชำระมัดจำพร้อมแนบสลิปและระบบตรวจสลิปปลอม แพ็กเกจสูงสุดเพิ่มข้อความแจ้งก่อนวันนัด การเลื่อนนัดและการยกเลิก fastwork.co
