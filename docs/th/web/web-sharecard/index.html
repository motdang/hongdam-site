ข้อมูลน่ารู้

  • Open Graph protocol ระบุคุณสมบัติที่จำเป็นของหน้าไว้สี่อย่าง คือ og:title, og:type, og:image และ og:url og:image คือ URL ของภาพที่เป็นตัวแทนของหน้า ส่วน og:image:alt เป็นคุณสมบัติคู่กันที่อธิบายภาพ ogp.me
  • หน้าการแชร์ของ Meta ระบุ og:image:width และ og:image:height คือความกว้างและความสูงของภาพเป็นพิกเซล และระบุว่าการตั้งค่านี้ช่วยให้ภาพโหลดถูกต้องตั้งแต่แชร์ครั้งแรก พร้อมชนิดภาพ image/jpeg, image/gif และ image/png developers.facebook.com
  • หน้าของ Meta ระบุว่าภาพถูกแคชตาม URL และจะไม่อัปเดตเว้นแต่ URL เปลี่ยน Sharing Debugger ของ Meta สั่งดึงข้อมูลหน้าใหม่และแสดงเมตาแท็กที่ตัวรวบรวมข้อมูลอ่านได้ พร้อมข้อผิดพลาดที่พบ developers.facebook.com
  • เอกสารของ Mastodon อธิบายว่า preview card คือตัวอย่างของ URL ที่ลิงก์ สร้างจาก OpenGraph tag มีหัวข้อและคำอธิบายของหน้าที่ลิงก์ และภาพย่อ docs.joinmastodon.org

คำถามที่คนถาม

Open Graph image คืออะไร

คือภาพที่ตั้งไว้ในคุณสมบัติ og:image ของหน้า เป็น URL ของภาพที่เป็นตัวแทนของหน้า Open Graph protocol ระบุ og:title, og:type, og:image และ og:url เป็นคุณสมบัติที่จำเป็นสี่อย่างของหน้า ogp.me

ทำไมภาพตัวอย่างเก่ายังอยู่หลังเปลี่ยนภาพ

หน้าของ Meta ระบุว่าภาพถูกแคชตาม URL และจะไม่อัปเดตเว้นแต่ URL เปลี่ยน การแสดงภาพใหม่จึงต้องเผยแพร่ภาพนั้นภายใต้ URL ใหม่ developers.facebook.com

ภาพตัวอย่างลิงก์เป็นไฟล์ชนิดใดได้บ้าง

หน้าการแชร์ของ Meta ระบุ image/jpeg, image/gif และ image/png เป็นชนิดของ og:image:type และระบุความกว้างความสูงของภาพเป็นพิกเซล ซึ่งช่วยให้ภาพโหลดถูกต้องตั้งแต่แชร์ครั้งแรก developers.facebook.com

ตัวอย่างลิงก์บน Mastodon มาจากไหน

เอกสารของ Mastodon ระบุว่า preview card สร้างจาก OpenGraph tag ของ URL ที่ลิงก์ มีหัวข้อและคำอธิบายของหน้าที่ลิงก์ และภาพย่อ docs.joinmastodon.org

เครื่องมือสร้างภาพแชร์ราคาเท่าไร
