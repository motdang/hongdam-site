  • ทำให้เสร็จ: งาน 15 ชั่วโมง฿30,000แก้ตามรายการ เพิ่มการทดสอบ และเผยแพร่บนบัญชีของคุณเอง ส่งรายการสิ่งที่เจอและที่แก้กลับให้

ข้อมูลน่ารู้

  • Lovable เชื่อมแต่ละโปรเจกต์กับที่เก็บโค้ด GitHub ที่มันสร้างให้ การเปลี่ยนแปลงใน Lovable ซิงก์ไป GitHub และสิ่งที่ผลักไปยังสาขาที่ใช้อยู่ซิงก์กลับ สามารถโคลนที่เก็บโค้ดมาทำงานต่อในโปรแกรมแก้โค้ดที่ชอบได้ และแพ็กเกจแบบชำระเงินดาวน์โหลดโค้ดทั้งหมดได้ docs.lovable.dev
  • หน้าของ Supabase ระบุว่าตารางใน schema ที่เปิดให้เข้าถึงโดยไม่เปิด row level security (RLS คือกฎว่าใครอ่านหรือแก้แต่ละแถวของตารางได้) จะอ่านและเขียนได้โดยบทบาทใดก็ตามที่ได้รับสิทธิ์ เมื่อเปิด RLS แล้ว API จะไม่ส่งข้อมูลให้ publishable key จนกว่าจะสร้างนโยบาย supabase.com
  • หน้าของ Stripe ระบุว่าคีย์ลับ (secret API key คือรหัสที่ให้ซอฟต์แวร์ทำงานในบัญชี Stripe) อยู่ในสภาพแวดล้อมฝั่งเซิร์ฟเวอร์ ไม่ใส่ในซอร์สโค้ด และไม่ฝังในแอป ส่วน publishable key ใส่ในหน้าเว็บและแอปได้อย่างปลอดภัย docs.stripe.com
  • หน้าของ Aibrify สำหรับแอป Lovable ระบุปัญหา ได้แก่ หน้าจอขาว ล็อกอินไม่ได้ ผู้ใช้เห็นหรือแก้ข้อมูลของผู้ใช้อื่น เผยแพร่ไม่ได้ แอปที่เผยแพร่แล้วต่างจากตัวอย่าง ข้อมูลไม่ถูกบันทึก ตารางที่ไม่มี row-level security และคีย์ที่ใช้ได้เฉพาะฝั่งเซิร์ฟเวอร์ถูกเปิดในเบราว์เซอร์ aibrify.com
