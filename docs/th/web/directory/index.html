llms.txt คืออะไร

llms.txt เป็นข้อเสนอให้มีไฟล์ Markdown ที่รากของเว็บหรือพาธใดก็ได้ เพื่อนำทางเอเจนต์ AI ในเว็บ ไฟล์ต้องมีหัวข้อ H1 เป็นชื่อเว็บ มีสรุปสั้น ๆ ได้ และมีส่วนที่เป็นรายการลิงก์ llmstxt.org
