สินค้า ราคาขายส่ง และใบแจ้งหนี้ สำหรับธุรกิจที่ขายให้ร้านค้า

ใช้อย่างไร

  1. ใส่สินค้า แต่ละชิ้นมี SKU (รหัสสินค้า) และราคา
  2. เขียนใบแจ้งหนี้ เปิด VAT แล้วระบบบวกให้ และไม่รับรายการขายส่งที่ต่ำกว่าขั้นต่ำ
  3. ออกใบแจ้งหนี้ เมื่อออกแล้วแก้ไขไม่ได้
  4. บันทึกการชำระเงินเมื่อได้รับ ทุกการบันทึกมีชื่อคนที่บันทึก
