คำถามที่คนถาม

แชทบอทไลน์ฟรีไหม

ข้อความตอบกลับ (reply) ของแชทบอทไม่นับรวมในจำนวนข้อความของแพ็กเกจ ข้อความ push, multicast, broadcast และ narrowcast นับตามจำนวนคนที่ได้รับ แพ็กเกจที่ไม่มีข้อความเพิ่ม ถ้าบัญชีส่งเกินจำนวนจะส่งไม่ได้และ LINE ตอบกลับเป็นข้อผิดพลาด แพ็กเกจที่ขายข้อความเพิ่มจะคิดเงินเป็นรายข้อความ developers.line.biz

LINE Official Account เดือนละเท่าไหร่

แพ็กเกจฟรีไม่มีค่าใช้จ่าย ส่งได้ 300 ข้อความต่อเดือน เบสิกเดือนละ ฿1,280 ได้ 15,000 ข้อความ โปรเดือนละ ฿1,780 ได้ 35,000 ข้อความ ราคายังไม่รวม VAT 7% ข้อความเพิ่มคิดข้อความละ ฿0.10 บนเบสิก และ ฿0.06 บนโปร lineforbusiness.com

LINE Messaging API คืออะไร

เป็นช่องทางให้เซิร์ฟเวอร์บอททำงานกับ LINE Official Account บอทตอบกลับคนที่เพิ่มบัญชีเป็นเพื่อนได้ ส่งข้อความเมื่อไรก็ได้ รับเหตุการณ์ผ่าน webhook และตั้ง rich menu ได้ LINE ระบุว่าเริ่มใช้ได้ฟรี developers.line.biz

webhook ของแชทบอทไลน์คืออะไร

webhook คือที่อยู่บนเซิร์ฟเวอร์ของบอท LINE ส่ง HTTP POST พร้อมเหตุการณ์มาที่นั่น เซิร์ฟเวอร์ตอบกลับด้วยรหัส 2xx ถ้าไม่ตอบและเปิดการส่งซ้ำไว้ LINE จะส่งเหตุการณ์นั้นอีกครั้ง LINE อาจหยุดส่งถ้าเซิร์ฟเวอร์รับไม่ได้เป็นเวลานาน developers.line.biz

ไลน์บัญชีเดียวแสดงเมนูต่างกันให้ลูกค้าแต่ละคนได้ไหม

ได้ ด้วย rich menu Messaging API ตั้ง rich menu ให้ผู้ใช้เป็นรายคนได้ เพื่อนที่เพิ่มบัญชีจะเห็น rich menu เริ่มต้น เว้นแต่ผู้ใช้คนนั้นถูกผูกกับ rich menu ของตัวเอง developers.line.biz

ลิงก์เปิดแชต LINE พร้อมข้อความที่พิมพ์ไว้แล้วได้ไหม

ได้ ที่อยู่คือ line.me/R/oaMessage/ ตามด้วย ID ของบัญชี แล้วตามด้วย ? และข้อความ ID และข้อความต้องเข้ารหัสแบบ percent-encoding ใช้ได้ใน LINE บน iOS และ Android ไม่ใช่ LINE บนพีซี developers.line.biz
