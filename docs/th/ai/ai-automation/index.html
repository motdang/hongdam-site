Zapier, Make, n8n และ Cloudflare นับการใช้งานอย่างไร

Zapier นับ 1 งานต่อการกระทำที่สำเร็จ Make นับ 1 เครดิตต่อการทำงานของโมดูล n8n นับ 1 execution คือการรันเวิร์กโฟลว์ทั้งชุดหนึ่งรอบ ไม่ว่ากี่ขั้นตอน ส่วน Cloudflare Worker นับ 1 คำขอ hongdam.net
