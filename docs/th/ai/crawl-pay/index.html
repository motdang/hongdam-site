ข้อมูลน่ารู้

  • pay per crawl ของ Cloudflare อยู่ในเบต้าปิด หน้าเว็บชี้ไปยังหน้าลงทะเบียน และลูกค้า Enterprise ติดต่อผู้ดูแลบัญชีของตนได้ developers.cloudflare.com
  • บอทที่ไม่จ่ายเงินจะได้คำตอบ HTTP 402 Payment Required (ต้องชำระเงิน) พร้อมราคา บอทที่ส่งเจตนาจ่ายเงินมาในส่วนหัวของคำขอจะได้คำตอบปกติ HTTP 200 developers.cloudflare.com
  • เจ้าของเว็บเป็นผู้ตั้งราคา บทความของ Cloudflare อธิบายราคาเดียวต่อคำขอทั่วทั้งเว็บ และเจ้าของให้บอทที่เลือกเข้าได้โดยไม่คิดเงิน blog.cloudflare.com
  • Cloudflare ทำหน้าที่เป็น Merchant of Record (ผู้ขายตามกฎหมายที่รับชำระเงิน) ของ pay per crawl กฎ WAF หรือ Bot Management ที่บล็อกบอทจะมีผลเหนือการเก็บเงิน บอทนั้นจึงเข้าไม่ได้ developers.cloudflare.com
  • AI Crawl Control ของ Cloudflare แสดงว่าบริการ AI ใดเข้าเว็บ ตั้งกฎอนุญาตหรือบล็อกแยกตามบอท และติดตามว่าบอทปฏิบัติตาม robots.txt หรือไม่ ใช้ได้กับทุกแพ็กเกจของ Cloudflare developers.cloudflare.com

คำถามที่คนถาม

pay per crawl ของ Cloudflare ราคาเท่าไร

บทความแนะนำไม่ระบุราคา มีเพียงตัวอย่างแทนที่ USD XX.XX เจ้าของเว็บเป็นผู้ตั้งราคาต่อคำขอ blog.cloudflare.com

ใครๆ ก็ใช้ pay per crawl ได้ไหม

ยังไม่ได้ Cloudflare ระบุว่าเป็นเบต้าปิด เจ้าของเว็บและผู้ดูแลบอทสมัครผ่านหน้าลงทะเบียน pay per crawl ของ Cloudflare และลูกค้า Enterprise ติดต่อผู้ดูแลบัญชีของตนได้ developers.cloudflare.com

เจ้าของเว็บเลือกอะไรได้บ้างกับบอทแต่ละตัว

สามทาง อนุญาตคือเข้าได้ฟรี คิดเงินคือเรียกราคาที่ตั้งไว้ทั้งโดเมน ใช้ได้แม้กับบอทที่ยังไม่มีความสัมพันธ์ด้านการเรียกเก็บเงินกับ Cloudflare บล็อกคือไม่ให้เข้าและจ่ายเงินไม่ได้ blog.cloudflare.com

ดูได้อย่างไรว่าบอทไหนทำตาม robots.txt ของฉัน

AI Crawl Control ของ Cloudflare มีแดชบอร์ดแสดงกิจกรรมของบอท และตรวจสอบการปฏิบัติตาม robots.txt แสดงว่าบอทไหนทำตามคำสั่ง และสร้างกฎบังคับใช้ได้ หน้าเว็บระบุว่าใช้ได้กับทุกแพ็กเกจของ Cloudflare developers.cloudflare.com
