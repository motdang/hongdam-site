    What people ask

    How does a crew split the work?

    CrewAI lists two ways. In the sequential process, tasks run one after another, in order. In the hierarchical process, a manager agent hands out the tasks and checks the results. docs.crewai.com

    How many agents does a problem need?

    Anthropic's guide: a simple fact-finding task takes 1 agent with 3 to 10 tool calls. A direct comparison takes 2 to 4 subagents with 10 to 15 calls each. Complex research takes more than 10 subagents with clearly divided duties. anthropic.com

    Which problems does a crew not suit?

    Anthropic names domains where all agents must share the same context or depend on each other a lot, and most coding tasks, which have fewer parts that can run in parallel. It adds that agents are not yet good at real-time coordination and delegation. anthropic.com

    Is a crew better than one agent?

    On Anthropic's own research test, a lead agent (Claude Opus 4) with subagents (Claude Sonnet 4) did 90.2% better than a single Claude Opus 4 agent. anthropic.com
