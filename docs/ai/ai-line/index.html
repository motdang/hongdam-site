Good to know

  • LINE had 56 million monthly active users in Thailand in late 2025, which is 78.2% of the population. In October 2025, 82.6% of Thailand's internet users were active LINE users. datareportal.com
  • A LINE Official Account in Thailand has three plans: Free with 300 messages a month, Basic at ฿1,280 with 15,000 messages, and Pro at ฿1,780 with 35,000. Prices are before 7% VAT. Extra messages cost ฿0.10 each on Basic and ฿0.06 each on Pro. lineforbusiness.com
  • LINE counts messages by the number of people who get them. One message sent to five people counts as five. Reply messages are not counted. Push, multicast, broadcast and narrowcast messages are counted. developers.line.biz
  • LINE sends a webhook event to the bot server's address when someone adds the account or sends it a message. The event gives the sender's user ID, and its destination field gives the ID of the bot that received it. developers.line.biz
  • A rich menu is a menu in a LINE chat. The Messaging API can set a rich menu for one user. That user sees it instead of the account's default rich menu. developers.line.biz
  • A link in the form line.me/R/oaMessage/ followed by the account's ID opens a chat with that account with text already typed in. It works in LINE for iOS and Android, not in LINE for PC. developers.line.biz

What people ask

Is a LINE chatbot free?

A chatbot's reply messages are not counted toward a plan's message amount. Push, multicast, broadcast and narrowcast messages are counted, one for each person who gets them. On a plan without extra messages, an account that goes past its amount cannot send, and LINE returns an error. Plans that sell extra messages bill them per message. developers.line.biz

How much does a LINE Official Account cost a month?

The Free plan costs nothing and has 300 messages a month. Basic is ฿1,280 a month for 15,000 messages. Pro is ฿1,780 a month for 35,000. Prices are before 7% VAT. Extra messages cost ฿0.10 each on Basic and ฿0.06 each on Pro. lineforbusiness.com

What is the LINE Messaging API?

It lets a bot server work with a LINE Official Account. A bot can send reply messages to people who added the account, send messages at any time, receive events through a webhook and set rich menus. LINE says you can start with it for free. developers.line.biz

What is a LINE chatbot webhook?

A webhook is an address on the bot's server. LINE sends an HTTP POST with the event to it. The server returns a 2xx code. If it does not, and redelivery is on, LINE sends the event again. LINE may stop sending if the server fails to receive them for a long time. developers.line.biz

Can one LINE account show a different menu to different customers?

Yes, with rich menus. The Messaging API can set a rich menu for one user. Friends see the default rich menu unless a user is linked to a rich menu of their own. developers.line.biz

Can a link open a LINE chat with a message already typed?

Yes. The address is line.me/R/oaMessage/ followed by the account's ID, then a ? and the text. The ID and the text are percent-encoded. It works in LINE for iOS and Android, not in LINE for PC. developers.line.biz
