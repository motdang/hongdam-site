    How a group starts

    About an hour, once.

    1. 1

      Add the desk to the group

      An admin adds the desk to the LINE group, like adding a member. From then on it files each new message.

    2. 2

      Send the old chat once

      In the group: menu, Settings, Export chat history. LINE makes a text file. Send it to the desk and the old messages are filed too.

    3. 3

      New members ask

      In the group with @desk, or on a page like this one. Questions nobody has answered yet go to the person who covers that subject.

    4. 4

      Each volunteer gets a link

      No password. The link opens the wheel with that person's cases. The coordinator's link hands cases out and checks them.
