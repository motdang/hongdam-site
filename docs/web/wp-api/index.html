Useful facts

  • WordPress has a REST API with endpoints for posts, pages, taxonomies and other built-in data types. Applications send and receive JSON at them to query, modify and create content. developer.wordpress.org
  • A request to /wp-json/wp/v2/posts returns a collection of posts; the defaults are 10 per page, status publish and context view. developer.wordpress.org
  • WordPress 6.9 added the Abilities API, a registry where plugins, themes and core describe what they can do in a machine-readable form. The post of 10 November 2025 calls it groundwork for AI agents and automation tools. make.wordpress.org
  • The Abilities API's REST endpoints sit under wp-abilities/v1 and exist only for abilities registered with show_in_rest set to true. The post says they require an authenticated user. make.wordpress.org

What people ask

Does WordPress already have an API?

Yes, a REST API comes with WordPress. It provides endpoints for posts, pages, taxonomies and other built-in data types, and returns JSON. developer.wordpress.org

What is the WordPress Abilities API?

It is a system in WordPress 6.9 where plugins, themes and core register what they do in a standard, machine-readable form. An ability takes a label, description, category, input and output schemas, an execute callback and a permission callback. make.wordpress.org

How does another app log in to the WordPress REST API?

Cookie authentication is WordPress's standard method, for a logged-in user inside WordPress. For other apps, application passwords pass credentials over HTTPS with Basic Auth. developer.wordpress.org

How much does a custom WordPress plugin cost?
