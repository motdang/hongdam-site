Useful facts

  • The Open Graph protocol lists four required properties for a page: og:title, og:type, og:image and og:url. The og:image property is the URL of an image that represents the page. A companion property, og:image:alt, describes the image. ogp.me
  • Meta's sharing page lists og:image:width and og:image:height, the image width and height in pixels, and says setting them helps the image load properly the first time it is shared. It lists image/jpeg, image/gif and image/png as the image types. developers.facebook.com
  • Meta's page says images are cached by URL and are not updated unless the URL changes. Its Sharing Debugger triggers a scrape of the page and shows the meta tags the crawler reads and any errors it finds. developers.facebook.com
  • Mastodon's documentation describes a preview card as a rich preview of a linked URL, generated using OpenGraph tags, with the title and description of the linked resource and a preview thumbnail. docs.joinmastodon.org

What people ask

What is an Open Graph image?

It is the image set in a page's og:image property, a URL for an image that represents the page. The Open Graph protocol lists og:title, og:type, og:image and og:url as the four required properties for a page. ogp.me

Why does an old preview picture stay after the picture is changed?

Meta's page says images are cached by URL and are not updated unless the URL changes. To show a new image, the page publishes it under a new URL. developers.facebook.com

Which file types can a link preview image be?

Meta's sharing page lists image/jpeg, image/gif and image/png as the types for og:image:type. It also lists the image width and height in pixels, which it says help the image load properly the first time it is shared. developers.facebook.com

Where does a Mastodon link preview come from?

Mastodon's documentation says a preview card is generated using OpenGraph tags from the linked URL. It carries the title and description of the linked resource and a preview thumbnail. docs.joinmastodon.org

How much do tools that make share images cost?

Bannerbear's pricing page lists US$49, US$149 and US$299 a month, in US dollars, with 1,000, 10,000 and 50,000 credits. One image render takes one credit, and the cost rises with the number of formats and the scale. bannerbear.com
