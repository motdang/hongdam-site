Good to know

  • For a move to a new host with no URL changes, Google's page lists these steps: copy and test the site on a temporary hostname, lower the DNS TTL (how long other computers keep an old DNS answer) to a few hours at least a week ahead, then update the DNS records. Traffic shifts from the old server to the new one, and the old host can be shut down when traffic to it reaches zero. developers.google.com
  • WordPress's documentation says a move begins with a backup of the files and the database. If the database and the URL stay the same, the site moves by copying its files and database. If the address changes, the page lists nine steps in sequence. developer.wordpress.org
  • Wix says a Wix site cannot be exported or hosted elsewhere, because it has to run on Wix's servers. A domain can be connected to a Wix site or managed with another provider. support.wix.com
  • Wix says a domain cannot be transferred within 60 days of its registration, of a change to the registrant's contact details, or of a previous transfer. The limit applies to transfers away from Wix too. support.wix.com
  • Microsoft's page says that when a domain's MX record changes to Microsoft 365, all new mail for the domain goes there, and existing mail stays at the previous email host unless it is moved. learn.microsoft.com

What people ask

Can I move a Wix site to another host?

Wix says a Wix site cannot be exported or hosted elsewhere, because it has to run on Wix's servers. Its page says the content you build belongs to you, and a domain can be connected to a Wix site or managed with another provider. support.wix.com

Is there a wait before a domain can move?

Wix says a domain cannot be transferred within 60 days of its registration, of a change to the registrant's contact details, or of a previous transfer. The limit applies to transfers away from Wix as well, and Wix cannot change it. In the meantime the domain can stay in the Wix account and point to the external site. support.wix.com

How is a WordPress site moved to a new server?

WordPress's documentation starts with a backup of the files and the database. If the database and the URL stay the same, the files and the database are copied across. If the address changes, the page lists nine steps in sequence, including changing the URLs and the settings in wp-config.php. developer.wordpress.org

How does the switch to a new host happen?

In Google's steps, the DNS records are updated to point at the new host after the copy is tested. The TTL is lowered to a few hours at least a week ahead, and public DNS checking tools show whether ISPs worldwide have picked up the new settings. Traffic shifts from the old server to the new one. developers.google.com

What does a Wix-to-WordPress move cost?

Seahawk Media's page for the service says it starts at US$499. seahawkmedia.com
