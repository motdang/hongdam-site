Good to know

  • Thai, Chinese, Japanese, Lao, Khmer and Myanmar put no spaces between words, so splitting text on spaces gives the wrong words. Browsers offer Intl.Segmenter to split such text into words, available across browsers since April 2024. developer.mozilla.org
  • Google's Custom Search JSON API is closed to new customers; existing customers have until 1 January 2027 to move to another solution. Google names Vertex AI Search as an alternative for up to 50 domains. developers.google.com
  • Pagefind, an independent open-source search library, works with any static HTML output and adds a static search bundle to the built files. It lists zero-config support for multilingual websites and runs without hosting any infrastructure. pagefind.app

What people ask

How do I add a search bar to my website?

A static-site library such as Pagefind adds a search bundle to the built files, and the search runs in the visitor's browser. It needs no hosted search service. pagefind.app

Can I use Google to search my own site?

Google's Custom Search JSON API is closed to new customers. Existing customers have until 1 January 2027 to move, and Google names Vertex AI Search for searching up to 50 domains. developers.google.com

Does site search work in Thai?

Thai puts no spaces between words, so splitting text on spaces gives the wrong words. Browsers offer Intl.Segmenter to split Thai and other such languages into words, available across browsers since April 2024. developer.mozilla.org

What does hosted site search cost?

Algolia's free plan includes 10,000 search requests a month and 50,000 records. On its Grow plan, extra requests cost US$0.50 per 1,000 and extra records US$0.40 per 1,000. algolia.com
